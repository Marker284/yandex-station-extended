# Веб-пульт и ТВ-набор для Станции 1

Один файл `install.sh` запускается в терминале Станции в AliceBridge. В нём уже
находятся сервер пульта и интерфейс; отсутствующие Couchy Launcher, SmartTube и
v2rayNG скачиваются из официальных GitHub-релизов с проверкой SHA-256.

Проверено на Станции 1 (`tulip`), Android 6.0.1 / SDK 23,
`ro.build.display.id=MOB30J.20261013`. На других моделях не проверялось.

## Установка

1. Получить root и включить SSH в AliceBridge. Нужен его штатный автозапуск
   `/data/dropbear/start.sh`; Entware, Python, Java и Android SDK для установки не нужны.
2. Открыть интерактивный терминал **колонки** в AliceBridge, передать туда `install.sh`
   и выполнить:

   ```sh
   sh /data/local/tmp/install.sh
   ```

3. Открыть напечатанный `SETUP_URL` на телефоне в той же сети и задать свой пароль
   длиной от 8 символов. Дальше используется обычный адрес `REMOTE_URL` и этот пароль.

Для установки из опубликованного репозитория команда загрузки приведена
в [рецепте вики](https://hackalice.me/recipes/station1-tv/).
До публикации обновления нужно использовать приложенный локальный `install.sh`.

Повторный запуск обновляет пульт и сохраняет пароль, настройки и данные приложений.
Уже установленные приложения пропускаются. Только пульт, без загрузки APK:

```sh
sh /data/local/tmp/install.sh --remote-only
```

Скрипт не меняет `/system` и boot, не перезагружает колонку и не останавливает Алису.
Для установки недостающих APK нужен интернет. Закреплены Couchy 1.0.6,
SmartTube stable 32.68 и v2rayNG 1.9.45; ссылки и хеши находятся в
[`src/install.template.sh`](src/install.template.sh).

`install.ps1` — самостоятельная альтернатива для Windows с OpenSSH, если удобнее
запускать установку с ПК:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Ip <STATION_IP>
```

## Управление

- Стрелки, OK, назад, меню, воспроизведение, громкость и отключение звука.
- Повтор стрелок и громкости при удержании; отпускание при разрыве соединения.
- Запуск Алисы, Couchy, SmartTube, v2rayNG, настроек Android и Wi-Fi.
- Ввод текста, включая кириллицу через вставку, если приложение её поддерживает.
- Импорт VPN-ссылки, смена пароля, выбор лаунчера при следующем включении.

Страница и сервер работают на самой Станции. Порт 8080 привязан к текущему IPv4
`wlan0`; при смене адреса служба обновляет привязку. Управление требует пароль,
сессию и проверку Origin/CSRF. Первый пароль задаётся по одноразовой ссылке;
в `/data/station-remote/auth.properties` хранится PBKDF2-хеш с солью.
Транспорт — локальный HTTP, поэтому порт нельзя публиковать в интернете.

Для кнопок используются Android InputManager / ActivityManager в постоянном
Java-процессе. В проверке 30 команд по Wi-Fi медиана времени ответа WebSocket —
4 мс, p95 — 9 мс; обработка внутри сервера — около 1–2 мс.
Это время команды, а не время отрисовки телевизора. Качество Wi-Fi влияет на задержку.

Режим «Couchy при загрузке» может отключить голос Алисы; по умолчанию выбрана Алиса.
Полный проход загрузки с Couchy и подключение к любому стороннему VPN не проверялись.

## Отключение и резервные копии

Остановить пульт и отключить его автозапуск, сохранив данные и приложения:

```sh
sh /data/station-remote/remote-start.sh stop
/sbin/busybox sed -i '\|/data/dropbear/remote.sh|d' /data/dropbear/start.sh
```

Скопированные при обновлении файлы находятся в `/data/station-remote/backups/`.
Путь последней копии записан в `/data/station-remote/last-backup`.
Команды возврата предыдущей версии приведены в рецепте вики.

## Сборка из исходников

Нужны Python 3.10+, JDK 17 и [D8/R8 8.3.37](https://dl.google.com/dl/android/maven2/com/android/tools/r8/8.3.37/r8-8.3.37.jar).
R8 можно сохранить как `tools/r8.jar` либо указать путь переменной `R8_JAR`.
JDK выбирается через `JAVA_HOME` или `PATH`.

```sh
python3 build.py
python3 check.py
```

На Windows используются те же команды с `python` вместо `python3`.
Результат — `install.sh` и `install.ps1`; файлы в `dist/` и `tools/` служебные.
Скрипт компилирует Java 7, собирает DEX для API 23 и встраивает архив в оба установщика.
`check.py` проверяет хеш, состав архива и совпадение встроенных файлов с исходниками.
SDK Android, Gradle и сторонние Python-пакеты не требуются.

## Файлы

- `src/StationRemote.java` — HTTP, WebSocket, авторизация и управление Android.
- `src/index.html` — интерфейс без внешних библиотек и запросов к CDN.
- `src/remote-start.sh` — автозапуск, наблюдение за процессом и адресом Wi-Fi.
- `src/install-on-speaker.sh` — установка, резервная копия и проверка запуска.
- `src/install.template.*` — шаблоны установщиков, APK и их SHA-256.

Старые `lighttpd`, CGI и `monkey` для этого пульта не используются.

# SSH на колонку с Windows одним скриптом

`install-ssh.bat` ловит колонку в сети сразу после сброса и ставит Dropbear SSH на порт
`2222`, пока сетевой ADB ещё открыт. После синхронизации с облаком колонка закрывает ADB,
и вручную набрать команды из [инструкции по SSH](../../docs/start/ssh.md) часто не
успеть.

Проверено: Станция Мини 2 с часами (`yandexmini_2`), прошивка 0.369.1.46, root DNS-методом,
Windows 10 и 11.

## Что нужно

- Клон или архив этого репозитория: скрипт берёт `contrib/bin/dropbear`,
  `contrib/bin/dropbearkey` и `contrib/yandex-noupdate.sh`.
- `adb.exe` из [platform-tools](https://developer.android.com/tools/releases/platform-tools):
  в `PATH`, в `C:\adb` или рядом со скриптом.
- Клиент OpenSSH: «Параметры» → «Приложения» → «Дополнительные компоненты» →
  «Клиент OpenSSH». В Windows 10 и 11 обычно уже стоит.
- Колонка с открытым root-ADB по сети (DNS-метод из [«Получение root»](../../docs/start/root.md)).

## Шаги

1. Запустите `contrib\windows-ssh\install-ssh.bat`.
2. Сбросьте колонку и подключите её в приложении. Скрипт ждёт сам.
3. Когда появится `SSH port 2222 is OPEN`, ответьте `Y`, если нужно отключить обновления
   через `yandex-noupdate.sh`. На запрос пароля нажмите Enter, пароль пустой.
4. Проверьте автозапуск: выдерните колонку из розетки, через 2 минуты запустите скрипт ещё
   раз. Он должен сразу найти SSH и пропустить установку.

## Как это работает

- `find-speaker.ps1` берёт сети тех адаптеров, у которых есть основной шлюз (`/24`), и
  параллельно проверяет порт. VPN и виртуальные адаптеры без шлюза пропускаются. Сеть, где
  «отвечают» почти все адреса, считается VPN-адаптером и игнорируется.
- Устройство считается колонкой, только если в нём есть `/data/quasar`. Другие ADB-устройства
  в сети (например, телевизор на Android TV с ADB на `5555`) пропускаются.
- `offline` и `unauthorized` не останавливают скрипт: он переподключается на следующем
  круге.
- `S99zdropbear` — тот же скрипт автозапуска, что в [инструкции по SSH](../../docs/start/ssh.md#dropbear).

## Откат

```sh
ssh -p 2222 root@<IP>
mount -o remount,rw /
rm /etc/init.d/S99zdropbear
mount -o remount,ro /
rm /data/opt/bin/dropbear /data/opt/bin/dropbearkey
```

Обновления возвращает `sh /data/opt/yandex-noupdate.sh restore`.

# JBL Link Portable (с Алисой)

JBL Link Portable с Алисой — портативная колонка на MediaTek и Yocto с systemd.
Задний USB-C передаёт данные: через него получен root ADB, без вскрытия корпуса.

**Проверено на:** JBL Link Portable с Алисой,
прошивка `1.80.0.228.3676569159.20251219.` и `1.80.0.16.1086317237.20210928`, 4 ноября 2026 года.
Версия колонки с Google Assistant не проверялась.

## Платформа в двух словах { #platform }

| Что | Значение |
|---|---|
| SoC | MediaTek, платформа aud8516; модель в device tree — `MT8167` |
| CPU | Cortex-A35, CPU part `0xd04` |
| Разрядность | `armv7l`, 32-битные ядро и userspace |
| ОЗУ | Около 494 МиБ доступно ядру, MemTotal 505584 KiB |
| Ядро | Linux `4.4.22` |
| ОС | Yocto «aud Baseline» 11.0.1, `poky-aud-systemd`, systemd 234 |
| Флеш | NAND Micron, 512 МиБ, UBI/UBIFS |
| Корень | UBIFS, смонтирован read-only |
| Данные | `/data` и `/var` — один записываемый том |
| USB | Задний USB-C; проверен кабель USB-C ↔ USB-C |
| SSH | Статический ARMv7 Dropbear 2026.94, порт 2222, вход по ключу |

Нужны программы для ARMv7. Сборки под aarch64 на этой прошивке не запускаются.

## Получение root { #root }

На старте прошивка предоставляет root ADB через USB. Два защищённых маркера в
постоянных данных сохраняют сетевой доступ после перезагрузки. Полная инструкция:
[ADB, блокировка OTA и SSH с автозапуском](../start/root-jbl-link-portable.md).

## Чем отличается от Link Music { #differences }

У [Link Music](jbl-link-music.md) используется сервисный Micro-USB под подложкой.
У Portable проверен внешний USB-C на задней стороне. Доступ через зарядную базу
не проверялся; колонка подключалась кабелем непосредственно к компьютеру.

Здесь нет каталога `/etc/init.d`, а корень защищён от записи. Автозапуск через
Buildroot-скрипты других Станций не подходит. Проверенный способ использует
штатный сборщик логов и собственные файлы в `/data`, корень не изменяется.

## Индикация { #led }

В sysfs обнаружены `power-white`, `red`, `white1`–`white5` и `wifi`.
Соответствие физическим индикаторам и управление ими не проверялись.

## Звук { #audio }

В прошивке есть ALSA, `aplay`, `arecord` и `amixer`. Штатный звуковой тракт
использует обработчики Harman. Их наличие не подтверждает совместимость
готовых пакетов AirPlay или стороннего голосового помощника.

# JBL Link Portable (с Алисой)

JBL Link Portable с Алисой — портативная колонка на MediaTek и Yocto с systemd.
Задний USB-C передаёт данные: через него получен root ADB, без вскрытия корпуса.

**Проверено на:** JBL Link Portable с Алисой,
прошивка `1.80.0.228.3676569159.20251219.`, 4 ноября 2026 года.
Версия колонки с Google Assistant не проверялась.

ADB, SSH и автозапуск через Fluent Bit проверены также на прошивке 2021 года
`1.80.0.16.1086317237.20210928` (quasar 3.21), ноябрь 2026. На ней шаги выполнялись
вручную, `install-ssh.sh` не запускался. Разделы про индикацию и звук ниже проверены
на этой прошивке.

## Платформа в двух словах { #platform }

| Что | Значение |
|---|---|
| SoC | MediaTek, платформа aud8516; модель в device tree — `MT8167` |
| CPU | Cortex-A35, CPU part `0xd04` |
| Разрядность | `armv7l`, 32-битные ядро и userspace |
| ОЗУ | Около 494 МиБ доступно ядру, MemTotal 505584 KiB |
| Ядро | Linux `4.4.22` |
| ОС | Yocto «aud Baseline» 11.0.1, `poky-aud-systemd`, systemd 234 |
| Флеш | NAND Micron, 512 МиБ, UBI/UBIFS |
| Корень | UBIFS, смонтирован read-only |
| Данные | `/data` и `/var` — один записываемый том |
| USB | Задний USB-C; проверен кабель USB-C ↔ USB-C |
| SSH | Статический ARMv7 Dropbear 2026.94, порт 2222, вход по ключу |

Нужны программы для ARMv7. Сборки под aarch64 на этой прошивке не запускаются.

## Получение root { #root }

На старте прошивка предоставляет root ADB через USB. Два защищённых маркера в
постоянных данных сохраняют сетевой доступ после перезагрузки. Полная инструкция:
[ADB, блокировка OTA и SSH с автозапуском](../start/root-jbl-link-portable.md).

## Чем отличается от Link Music { #differences }

У [Link Music](jbl-link-music.md) используется сервисный Micro-USB под подложкой.
У Portable проверен внешний USB-C на задней стороне. Доступ через зарядную базу
не проверялся; колонка подключалась кабелем непосредственно к компьютеру.

Здесь нет каталога `/etc/init.d`, а корень защищён от записи. Автозапуск через
Buildroot-скрипты других Станций не подходит. Проверенный способ использует
штатный сборщик логов и собственные файлы в `/data`, корень не изменяется.

## Обновления { #ota }

Кроме каталога загрузок `/bkupgrade` обновление запускают два скрипта:
`/system/vendor/quasar/device_ota_update.sh` и `/system/vendor/quasar/a01localupdate`.
Корень защищён от записи, поэтому их можно только перекрыть: `mount -o bind /bin/true` поверх
каждого файла при каждой загрузке. Проверено на прошивке 2021 года: после перезагрузки
оба монтирования на месте. Хук автозапуска и способ отката —
в [описании защиты от обновлений](https://github.com/lemeshovich/jbl-link-portable-hackalice/blob/main/docs/ru/04-ota-protection.md).

## Индикация { #led }

В sysfs есть `power-white`, `red`, `white1`–`white5` и `wifi`. `white1`–`white5` —
это индикатор заряда на задней стороне, а не кольцо спереди.

Передним кольцом (фиолетовое, когда Алиса слушает, бегущее, когда думает, синее при
Bluetooth, красное при выключенных микрофонах) управляет сам `maind` через `/dev/i2c-led`
и держит устройство открытым. Протокол неизвестен, команды для кольца в IPC квазара нет.

## Звук { #audio }

В прошивке есть ALSA, `aplay`, `arecord` и `amixer`. Штатный звуковой тракт
использует обработчики Harman. Их наличие не подтверждает совместимость
готовых пакетов AirPlay или стороннего голосового помощника.

| Что | Значение |
|---|---|
| Голос Алисы | PCM `default` → softvol `ShadowMaster` (numid 120) → `dmixer` |
| Bluetooth | PCM `hmpp` — обработка Harman, через неё звучит настроенный бас |
| Кнопки громкости | двигают `Master` (numid 128) и `ShadowMaster`, 0–999 |
| Усиление кодека | `HW Gain1 Volume` (numid 7), в норме `524288`; выставляет `linkplay.service` при старте |
| Запись микрофонов | `hw:0,1`, `S32_LE`, 16 кГц, 2 канала; занят `maind` |
| Запись того, что играет колонка | `hw:0,5` (AWB_Record) |
| Декодеры GStreamer | MP3 через libmad; AAC и разбора MP4 нет |

!!! warning "`amixer sget Master` после загрузки глушит колонку"
    На только что загруженной колонке `amixer -c0 sget Master` или `sset Master` сбрасывает
    `HW Gain1 Volume` до `64`, и колонка почти замолкает, Алиса тоже. Вернуть усиление через
    `amixer cset` нельзя, помогает только `systemctl restart linkplay.service`. После такого
    перезапуска та же команда уже ничего не ломает, поэтому проблема легко прячется.
    Обращение к элементу напрямую безопасно: `amixer -c0 cget numid=128`,
    `amixer -c0 cset numid=128 500,500`. Проверено на прошивке 2021 года.

Подробнее про ALSA, свой выход через обработку Harman и зависшие подключения к `dmix` —
в [описании звука](https://github.com/lemeshovich/jbl-link-portable-hackalice/blob/main/docs/ru/07-audio.md).

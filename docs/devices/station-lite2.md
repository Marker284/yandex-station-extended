# Станция Лайт 2 (plum)

Розничное имя — **Яндекс Станция Лайт 2**; кодовое имя платформы — **Plum** (`yandex,station-lite2` / `amlogic, axg`).

Второе поколение популярной компактной колонки. Участники сообщества разобрали устройство и исследовали его прошивку.

---

## Платформа и аппаратная часть

В отличие от Станции Стрит (где Яндекс перешёл на дешёвый 32-битный чип Amlogic A1), в **Станции Лайт 2 производитель вернулся к проверенному семейству Amlogic AXG (A113X)**!

| Параметр | Значение |
|---|---|
| **Кодовое имя** | `plum` |
| **SoC** | **Amlogic AXG (A113X)**, `amlogic, axg` |
| **Архитектура CPU** | 4× ARM Cortex-A53, до **1.2 ГГц** |
| **Ядро** | Linux **4.9.68 aarch64** (64-бит) |
| **Userspace** | **32-бит armhf**, Buildroot, glibc 2.30 |
| **Память** | 256 МБ NAND SLC, UBI поверх MTD |
| **Прошивка** | Quasar 3.21 (нативный монолит `maind`) |
| **Беспроводная связь** | Wi-Fi 2.4 / 5 ГГц + Bluetooth (комбо-чип Unisoc) |
| **Питание** | USB Type-C (5V) |

---

## Ключевые отличия от Лайт 1-го поколения

1. **Кодовое имя прошивки:**
   * У Лайт 1: `yandexmicro` / `micro`.
   * У Лайт 2: **`plum`**.
2. **Звуковой тракт и динамик:**
   * Мощность звука увеличена до 6 Вт (в первой версии было 5 Вт).
   * Новый компактный широкополосный излучатель и переработанная акустическая камера.
3. **LED-индикация:**
   * Световые анимации переработаны, сохранено кольцевое расположение светодиодов в верхней части корпуса.
4. **Свой способ получить root:** [патч retail CA из factory](../start/retail-ca.md) —
   работает и на сборках после обновления 21 октября 2026 года, которые обычный DNS-метод
   уже не открывает.

## Получение root { #root }

**Основной способ — [патч retail CA из factory](../start/retail-ca.md).** Прошивка остаётся
на месте, в retail-разделе меняется только CA-бандл:

1. Поднимите [eQuasar](https://git.gay/iwakura/eQuasar/) — он отвечает
   `{"hasUpdate":false}` и включает сетевой ADB.
2. Загрузите колонку в factory mode (зажать кнопку отключения микрофона и подать питание)
   и подключите её к сети с DNS eQuasar.
3. По root ADB (`adb connect <IP_колонки>:5555`) подключите retail-раздел и замените CA-бандл.
4. Верните normal-загрузку — обычная прошивка поднимется с root ADB через eQuasar.

Полная последовательность с проверками — **[Root на Лайт 2: retail CA из factory](../start/retail-ca.md)**,
дальше — [SSH и отключение обновлений](../start/ssh.md).

С Android-телефона, без компьютера — **[AliceBridge](../start/root-android.md)**: поддержка
Лайт 2 добавлена, получение root проверено. На каких сборках прошивки он работает, пока
не уточнялось.

??? note "Запасной вариант для старых сборок"
    Сборки до 21 октября 2026 года ещё открываются обычным [DNS-методом](../start/root.md)
    (сброс зажатой кнопкой отключения микрофона, дальше — как для остальных моделей).

## AirPlay { #airplay }

AirPlay 2 работает вместе с Алисой: через [bt-proxy](../recipes/bt-proxy.md) она видит AirPlay
как Bluetooth-телефон и сама разводит его со своей музыкой, «дальше / пауза» и громкостью —
[рецепт](../recipes/airplay.md#lite2).

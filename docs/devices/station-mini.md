# Станция Мини (1-е поколение)

Розничное имя — **Яндекс Станция Мини** (первое поколение). SoC — Amlogic AXG, как у
[Лайта](station-lite.md) и [Мини 2](station-mini2.md), но прошивка заметно
«переходная»: старее userspace (Buildroot 2017.02), **SELinux в enforcing**, разметка
с **A/B-слотами** и ЦАП/сенсорика другого поколения.

Общие механизмы — в разделе [«Как это устроено»](../internals/architecture.md).

## Платформа в двух словах { #platform }

| Что | Значение |
|---|---|
| SoC | **Amlogic AXG**, `amlogic, axg` |
| CPU | 4× Cortex-A53 (`0xd03`), до **1.2 ГГц** (100/250/500/667/1000/1200 МГц) |
| ОЗУ | **~236 МБ** (MemTotal 242028 kB) |
| Флеш | **NAND Toshiba 256 МБ SLC** (`TC58NVG1S3HBAI4`), UBI поверх MTD |
| Ядро | Linux **4.9.68** aarch64 (сборка 20260928) |
| Userspace | Buildroot **2017.02** (старее, чем у Лайта/Мини 2) |
| ЦАП | **PCM5122** (TI) |
| Микрофоны | мик-массив (контроллер `MicArray_0` по I2C) + PDM |
| Датчик жестов | **ST VL53L0X** (ToF лазерный дальномер) |
| Индикация | кольцо через I2C (`ledring` + **SN3236**), не через sysfs-leds |
| Радио | **Broadcom/Cypress** (модуль `dhd` — FullMAC) |
| Кнопки | ADC-клавиатура (`adc_keypad`) |
| Выход на наушники | есть |
| quasar | 3.21 (`1.369.4.24.4711907614.20260928`) |

## Получение root { #root }

Для **YNDX-0004** описан [Station Mini Root — способ по USB/TPL][usb-root-guide]
для Windows x64 и Linux x86_64. Программа сохраняет собственный `system` колонки,
собирает изменённый образ, проверяет полное обратное чтение и `uid=0` после загрузки.
Разбирать корпус, менять DNS или выполнять заводской сброс для этого способа не нужно.
После подтверждения root автоматически устанавливается менеджер Alice Homebrew.

Запасные пути: универсальная [подмена DNS](../start/root.md) со сбросом колонки и
[AliceBridge](../start/root-android.md) с Android-телефона — оба на Мини 1 проверены.

Ограничения по номеру прошивки нет; совместимость проверяется по разметке и компонентам.
Неизвестный вариант останавливается до записи. Инструкция, условия работы, ссылки
на проект и восстановление исходного бэкапа — на [странице способа][usb-root-guide].

[usb-root-guide]: ../start/root-mini1-usb.md

## Чем отличается { #differences }

- **Другой Wi-Fi:** Broadcom/Cypress FullMAC (модуль **`dhd`**) — на Лайте/Мини 2
  Unisoc UWE5621.
- **ЦАП PCM5122** (TI) вместо ES8156/NTP8910A.
- **Датчик жестов ST VL53L0X** (ToF, `1-0x29`) — определяет поднесённую руку/
  расстояние (жесты над колонкой).
- **Индикация через I2C** (`ledring` на `1-0x1f` + LED-драйвер **SN3236** на
  `0-0x3c`); sysfs `/sys/class/leds` пуст.
- **SELinux `enforcing`**, разметка с **A/B-слотами** (`slot_suffix=_a`), загрузка
  `ramfs`→`init`→ubifs. На Лайте SELinux нет, слотов нет.
- **rootfs смонтирован RW** (`/dev/ubi0_0 / ubifs rw`) — в отличие от RO на Лайте.
- Userspace **Buildroot 2017.02** (значительно старше).

!!! warning "Политика SELinux блокирует запуск сторонних программ даже под root"
    Из-за режима `enforcing` политика SELinux может блокировать запуск сторонних
    бинарников и доступ к устройствам даже для пользователя root. Наличие слотов A/B
    означает дублирование системных разделов — учитывайте это при любых правках прошивки.

## Разделы флеша { #partitions }

```text
mtd0 "bootloader" 2 MB   mtd1 "tpl" 2 MB   mtd2 "boot" 10 MB
mtd3 "system" ~80 MB -> ubi0:rootfs (ubifs)
mtd4 "nv" 1 MB   mtd5 "bkupgrade" 105 MB -> ubi1 = /bkupgrade
mtd6 "recovery" ~50 MB
```

NAND — Toshiba 256 МБ SLC (ID `0x98 0xda`), page 2048, OOB 128.

## Шина I2C и периферия { #i2c }

| Шина:адрес | Чип | Назначение |
|---|---|---|
| `0-0x3c` | **SN3236** | LED-драйвер кольца |
| `1-0x10` | **MicArray_0** | контроллер микрофонного массива |
| `1-0x1f` | `ledring` | адресация LED-кольца |
| `1-0x29` | **ST VL53L0X** (stmvl53l0) | ToF-датчик расстояния/жестов |
| `1-0x4c` | **PCM5122** | аудио-ЦАП (TI) |

## Звук { #audio }

- ALSA card0 `AML-AUGESOUND`: `TDM-B` и `TDM-C` (playback+capture), `PDM` (микрофоны).
- ЦАП **PCM5122**. Есть выход на наушники.

## Вход { #input }

- `STM VL53L0 proximity sensor` — жесты/приближение (ToF).
- `adc_keypad` — физические кнопки через ADC.
- `AML-AUGESOUND Headphones` — детект наушников.

## Индикация { #led }

В Станции Мини 1 каталог `/sys/class/leds/` пуст. Кольцом подсветки по шине I2C
управляет 18-канальный ШИМ-контроллер **SI-EN SN3236** на `/dev/i2c-0` (адрес `0-0x3c`).

!!! note "Узел `1-001f` в Device Tree физически не распаян"
    Запись `ledring` на шине `i2c-1` осталась от референсной платы LinkPlay A98. На серийной
    плате YNDX-0004 по этому адресу ничего нет, а все шесть светодиодов подключены к
    контроллеру SN3236 на шине `i2c-0`.

### Кольцевая подсветка (6 RGB-зон) { #led-ring }

- Устройство: контроллер **SI-EN SN3236** на шине `/dev/i2c-0`, адрес `0x3c` (только запись).
- Формат цвета: **24 бита на светодиод (BGR)** — синий, зелёный, красный по одному байту.
- Размер буфера яркости: **18 байт** в регистрах `0x01..0x12` (6 зон × 3 канала).

#### Карта регистров SN3236 { #led-registers }

| Регистр | Назначение | Значения |
|---|---|---|
| `0x00` | Питание чипа (`Shutdown`) | `0x01` — рабочий режим, `0x00` — выключен |
| `0x01..0x12` | Яркость 6 светодиодов (18 каналов BGR) | зона 1: `0x01`=B, `0x02`=G, `0x03`=R … зона 6: `0x10`=B, `0x11`=G, `0x12`=R |
| `0x25` | Защёлка кадра (`PWM Update`) | запись `0xAA` синхронно применяет регистры `0x01..0x12` и `0x26..0x37` |
| `0x26..0x37` | Включение каналов (`LED Control`) | `0x01` — канал включён на полном токе, `0x00` — канал отключён |
| `0x4B` | Частота ШИМ (`PWM Frequency`) | `0x01` — 22 кГц (без наводки на микрофоны), `0x00` — 3 кГц |
| `0x4F` | Сброс (`Reset`) | запись `0x00` сбрасывает все регистры чипа |

#### Прямое управление цветом из консоли { #led-console }

В прошивку входит утилита `i2cset` с поддержкой блочной записи (флаг `i`). Запись в
регистры яркости вступает в силу только после отправки `0xAA` в регистр защёлки `0x25`.
Команды ниже инициализируют контроллер и заливают кольцо выбранным цветом:

```sh
# 1. Инициализировать чип (включить питание, разрешить 18 каналов, ШИМ 22 кГц):
i2cset -y 0 0x3c 0x00 0x01
i2cset -y 0 0x3c 0x26 \
  0x01 0x01 0x01 0x01 0x01 0x01 0x01 0x01 0x01 \
  0x01 0x01 0x01 0x01 0x01 0x01 0x01 0x01 0x01 i
i2cset -y 0 0x3c 0x4b 0x01
i2cset -y 0 0x3c 0x25 0xaa

# 2. Залить все 6 зон красным цветом (#FF0000 -> B=0x00, G=0x00, R=0xFF):
i2cset -y 0 0x3c 0x01 \
  0x00 0x00 0xff  0x00 0x00 0xff  0x00 0x00 0xff \
  0x00 0x00 0xff  0x00 0x00 0xff  0x00 0x00 0xff i && \
i2cset -y 0 0x3c 0x25 0xaa

# 3. Залить все 6 зон синим цветом (#0000FF -> B=0xFF, G=0x00, R=0x00):
i2cset -y 0 0x3c 0x01 \
  0xff 0x00 0x00  0xff 0x00 0x00  0xff 0x00 0x00 \
  0xff 0x00 0x00  0xff 0x00 0x00  0xff 0x00 0x00 i && \
i2cset -y 0 0x3c 0x25 0xaa

# 4. Залить все 6 зон фиолетовым цветом Алисы (#6B0FFF -> B=0xFF, G=0x0F, R=0x6B):
i2cset -y 0 0x3c 0x01 \
  0xff 0x0f 0x6b  0xff 0x0f 0x6b  0xff 0x0f 0x6b \
  0xff 0x0f 0x6b  0xff 0x0f 0x6b  0xff 0x0f 0x6b i && \
i2cset -y 0 0x3c 0x25 0xaa

# 5. Погасить всё кольцо:
i2cset -y 0 0x3c 0x01 \
  0x00 0x00 0x00  0x00 0x00 0x00  0x00 0x00 0x00 \
  0x00 0x00 0x00  0x00 0x00 0x00  0x00 0x00 0x00 i && \
i2cset -y 0 0x3c 0x25 0xaa
```
#### Системные анимации { #led-patterns }

Штатные световые паттерны хранятся в каталоге `/system/vendor/quasar/ledpatterns/*.led`.
Внутри файлов цвета записаны в обычном порядке RRGGBB: шесть колонок по числу зон и
длительность кадра в миллисекундах. Перестановку каналов в аппаратный BGR выполняет
сам демон перед вызовом библиотеки `libwmlighteffect.so`.
Воспроизвести штатный эффект можно утилитой `led_util`. Она не завершается сама после
окончания паттерна, а фоновые задачи в оболочке игнорируют `SIGINT`, поэтому процесс
останавливают через `kill -9` и затем гасят кольцо:

```sh
# Запустить анимацию на 3 секунды, затем остановить и погасить кольцо:
LD_LIBRARY_PATH=/system/vendor/quasar/libs /system/vendor/quasar/led_util \
  /system/vendor/quasar/ledpatterns/alice_pro_speaking.led &
LED_PID=$!; sleep 3; kill -9 $LED_PID 2>/dev/null
i2cset -y 0 0x3c 0x01 \
  0x00 0x00 0x00  0x00 0x00 0x00  0x00 0x00 0x00 \
  0x00 0x00 0x00  0x00 0x00 0x00  0x00 0x00 0x00 i && \
i2cset -y 0 0x3c 0x25 0xaa
```

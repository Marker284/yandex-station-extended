# Станция Мини 3 (bergamot)

Розничное имя: **Яндекс Станция Мини 3** (в модификациях с LED-часами и без них).
Кодовое имя: **bergamot**, в device tree модель `Yandex Bergamot EVT1`, совместимость
`yandex,bergamot-evt1`, `yandex,bergamot`, `amlogic, axg`.

Не путать с [Мини 3 Про](station-mini3-pro.md): у неё после перезагрузки сохраняется только
`/data`.

Это третье поколение компактных Станций на платформе Amlogic. Данные ниже сняты в октябре
2026 с розничной колонки на прошивке `0.369.1.50.4795902939.20261021.117`: sysfs, `/proc`,
`/etc/asound.conf` и `quasar.cfg`.

## Платформа в двух словах { #platform }

| Параметр | Значение |
|---|---|
| **Кодовое имя** | `bergamot` |
| **SoC** | **Amlogic AXG**, модель кристалла не проверялась |
| **CPU** | 4× ARM Cortex-A53 (`0xd03`), до **1.2 ГГц** (100/250/500/667/1000/1200 МГц) |
| **ОЗУ** | **~244 МБ** (MemTotal 243908 kB) |
| **Флеш** | **NAND SLC 512 МБ**, страница 4096 байт, разметка UBI поверх MTD |
| **Ядро** | Linux **4.9.68 aarch64** (64-бит), PREEMPT, сборка от 21.10.2026 |
| **Userspace** | **32-бит armhf**, glibc 2.30, Buildroot |
| **Сетевые интерфейсы** | Wi-Fi 2.4 / 5 ГГц + Bluetooth 5.0 |
| **Усилитель** | **ACM8625**, отдельного ЦАП нет |
| **Микрофоны** | 3 PDM |
| **Индикация** | 6 RGB-зон кольца на **AW21018** + LED-часы на **AW21036** |
| **Аудиовыход** | Встроенный динамик; разъема 3.5 мм нет |
| **Порт питания** | USB Type-C (5V / 9V), PD-контроллер **HUSB238** |
| **factory-образ** | `0.6.1.4.…factory-6` или `0.4.1.39.…factory-4` |

!!! note "64-битное ядро сочетается с 32-битным userspace"
    Как и на Станциях Лайт и Мини 2, ядро Linux здесь 64-битное (`aarch64`), а пользовательские
    процессы Quasar скомпилированы под 32-битный `armhf`. Сторонний софт собирайте со
    статической линковкой под `aarch64-linux-musl`.
    Подробности — в руководстве [Сборка софта](../internals/toolchain.md).

## Получение root { #root }

Способ зависит от сборки прошивки:

- **после обновления 21 октября 2026 года** (`0.369.1.50…`) DNS-метод не работает — используйте
  **[retail CA и маркеры из factory](../start/retail-ca-mini3.md)**: в factory mode правится
  CA-бандл retail-раздела, а в `/data` кладутся маркеры сетевого ADB и конфиг Wi-Fi;
- **старые сборки** открываются универсальным [DNS-методом](../start/root.md#dns-unlock)
  (перехват через `179.254.167.126`).

Дальше — [SSH и отключение обновлений](../start/ssh.md).

??? note "Закрепление доступа на старых сборках выполнялось в три шага"

    После первого входа по `adb connect <IP>:5555`:

    1. Перемонтируйте файловую систему: `mount -o remount,rw /`
    2. Отключите `updatesd` в `/etc/launch.json`.
    3. Зафиксируйте флаги автозапуска ADB в `/data/quasar/` через `chattr +i`.

## Чем отличается { #differences }

Ближайшая модель: [Мини 2](station-mini2.md), данные по ней взяты с ее страницы.

| | Мини 2 | Мини 3 |
|---|---|---|
| Кольцо | sysfs `mini2:*:ring{1..6}`, IS31FL3236 | framebuffer `/dev/fb0` 6×1, AW21018 |
| Часы | IS31FL3236 | AW21036 |
| Звук | ЦАП ES8156 + усилитель SY6045S, выход на наушники | усилитель ACM8625, наушников нет |
| Сенсорные кнопки | AW96103, `1-0x12` | `aw933xx_aw9610x`, `0-0x12` |
| RTC | DS1307 | на I2C нет |
| Флеш | NAND 256 МБ, страница 2048 | NAND 512 МБ, страница 4096 |
| `/tee` | vfat | jffs2 |
| Модули радио | `uwe5621_bsp_sdio`, `sprdwl_ng`, `sprdbt_tty` | `vlsicomm`, `aml_sdio`, `sdio_bt`, как на Лайте |

## Разделы флеша { #partitions }

Таблица разделов на прошивке `.50`, `/proc/mtd`:

| Раздел | Размер | Что внутри |
|---|---|---|
| mtd0 `bootloader` | 4 МБ | загрузчик |
| mtd1 `tpl` | 6 МБ | не разбирался |
| mtd2 `boot` | 20 МБ | ядро и рамдиск, зашифрованы |
| mtd3 `system` | 176 МБ | UBI `ubi0`, том `rootfs` (ubifs), монтируется в `/` только для чтения |
| mtd4 `nv` | 2 МБ | jffs2, `/tee` |
| mtd5 `bkupgrade` | 232,5 МБ | UBI `ubi1`, том `bkupgrade` → `/bkupgrade`; `/data` ведет в `/bkupgrade/data` |
| mtd6 `recovery` | 8 МБ | factory-образ |
| mtd7 `recovery_fs` | 51,5 МБ | factory-образ |

Сумма разделов 500 МБ, отсюда объем чипа 512 МБ. Блок стирания 256 КБ, OOB 256 байт.

- **`boot` зашифрован** Amlogic Secure Boot: раздел начинается с `AMLSECU!`, энтропия
  содержимого 8 бит на байт, в cmdline `androidboot.rh_unlock=0`. Ядро и рамдиск
  поправить нельзя, все правки живут в `system` и `/data`.
- **В `system` нет dm-verity.** После `mount -o remount,rw /` и `sync` правки остаются на
  флеше и переживают перезагрузку.
- **Factory-образ разбит на два раздела** только в таблице розничной прошивки. Ядро factory
  видит то же место одним разделом `recovery` на 59,5 МБ и грузит оттуда ramfs.
- OTA переписывает mtd0–mtd4. `/data` на mtd5 переживает и OTA, и перезагрузку; что из этого
  следует для root, разобрано в [шаге 9](../start/retail-ca-mini3.md).

## Индикация { #led }

В отличие от Станции Лайт и Мини 2, где светодиодами управляет стандартный интерфейс ядра
`/sys/class/leds/`, в Мини 3 кольцо управляется напрямую через фреймбуфер.

### Кольцевая подсветка (6 RGB-зон) { #led-ring }
- Устройство: **`/dev/fb0`** (виртуальный дисплей размером 6×1 пикселей).
- Формат цвета: **24 бита на пиксель (BGR)** — синий, зелёный, красный (по 1 байту на цвет).
- Размер буфера: ровно **18 байт** (6 зон × 3 байта).

#### Прямое управление цветом из консоли { #led-console }
```sh
# Залить все 6 зон синим цветом (B=40, G=00, R=00):
printf '\100\000\000\100\000\000\100\000\000\100\000\000\100\000\000\100\000\000' > /dev/fb0

# Залить все 6 зон фиолетовым цветом Алисы (#7A55FF -> B=FF, G=55, R=7A):
printf '\377\125\172\377\125\172\377\125\172\377\125\172\377\125\172\377\125\172' > /dev/fb0

# Погасить всё кольцо:
dd if=/dev/zero of=/dev/fb0 bs=18 count=1 2>/dev/null
```

Классы в `/sys/class/leds/bergamot:{red,green,blue}:logoN` имеют триггер `ledfb-logo`
и лишь пассивно отражают состояние буфера `/dev/fb0`.

#### Порядок зон { #led-zones }

Перед колонки там, где часы. Если смотреть сверху, зоны идут по часовой стрелке:

| Пиксель `/dev/fb0` | Байты | Где на кольце |
|---|---|---|
| 0 | 0–2 | справа, у кнопки «+» |
| 1 | 3–5 | спереди справа |
| 2 | 6–8 | спереди слева |
| 3 | 9–11 | слева, у кнопки «−» |
| 4 | 12–14 | сзади слева |
| 5 | 15–17 | сзади справа |

Резкой границы между зонами не получится: свет растекается по световоду.

#### Цвет { #led-color }

Байт в `/dev/fb0` прямо задает скважность ШИМ канала AW21018. Гамма-коррекции на этом пути
нет, у кольца в device tree нет цветокоррекции, коэффициенты тока `current_coefs` у каналов
одинаковые. Поэтому цвет из sRGB на кольце выглядит иначе, чем на экране: `#FFFFFF` уходит
в синеву, `#D52B1E` выглядит коралловым, `#0039A6` голубым.

Белый в штатных анимациях `oknix/*.led` записан как `FFEECC`. Чтобы цвет на кольце был
похож на экранный, переводите sRGB в линейную шкалу и ослабляйте зеленый и синий так же,
как в этом белом: G×0,93, B×0,80.

В `/system/vendor/quasar/ledconfigs/` лежат шесть файлов `beige`, `green`, `pink`, `purple`,
`red`, `yellow` (`.json`) с матрицей 3×3 (`"type": "matrix"`). По именам это похоже на
поправку цвета под цвет ткани корпуса. Какой файл выбирает прошивка и к чему его применяет,
не проверялось. Запись в `/dev/fb0` идет мимо `maind`, и матрица в ней не участвует.

#### Системные анимации { #led-patterns }
Штатные световые паттерны хранятся в каталоге `/system/vendor/quasar/ledpatterns/oknix/*.led`
(35 файлов). Воспроизвести любой системный эффект можно утилитой:
```sh
led_util /system/vendor/quasar/ledpatterns/oknix/alice_listening.led
```

### LED-часы (в моделях с дисплеем) { #clock }

В модификации с часами за вывод времени, температуры и анимаций («глазки», смайлики)
отвечает драйвер `clock_led_util` (симлинк на `maind`).

Часы собраны на драйвере AW21036 (`0-0x35`): 32 белых светодиода, каждый виден в sysfs
отдельным светодиодом с яркостью 0–255 и триггером `none`.

| Светодиоды | Что это |
|---|---|
| `bergamot:white:clock{A..G}{0..3}` | сегменты четырех цифр |
| `clockDH`, `clockDL` | двоеточие |
| `clockDM` | средняя точка; где она на корпусе, не проверялось |
| `clockDEGREE` | знак градуса |

Сегменты названы как у обычного семисегментного индикатора: A сверху, дальше B–F по
часовой стрелке, G в середине. Позиция 0 соответствует первой цифре часов. Так раскладку
описывает `leds.clock.frameBuilder` в `quasar.cfg`: `digitValues`, `digitIndices` и
`symbolValues` для двоеточия.

- Время `maind` рисует сам, записью в `brightness` каждого сегмента.
- Анимации часов лежат в `/system/vendor/quasar/ledpatterns/clock/*.binscled.zst`
  (11 файлов: `alice_listening`, `alice_speaking`, `blink`, `ringing` и другие). Они сжаты
  zstd, утилиты `zstd` на колонке нет.
- Для рисования собственных пиксельных иконок и анимаций используется скрипт
  `smiley_editor.py` из каталога `contrib/`.

## Звук { #audio }

- ALSA card0 `AML-AUGESOUND`: `hw:0,0` `TDM-B-acm8625` (воспроизведение на усилитель) и
  `hw:0,1` `PDM-dummy` (захват, 8 каналов).
- **Громкость.** `Master Playback Volume` (0–255) без шкалы в дБ, `amixer` пишет
  `TLV read error`. Служба `/usr/bin/hardvold` переводит его в `main Acm8625 AMP ChL/ChR
  Volume` усилителя (от −103 дБ, шаг 0,25 дБ). Кривую перевода не снимали. Есть еще
  переключатель `SPK mute`.
- **Bluetooth.** `bluealsa` 4.1.1 запущен с профилями `a2dp-sink`, `a2dp-source` и `hfp-ag`,
  кодек только SBC (`--sbc-quality=high`). Звук с телефона играет `bluealsa-aplay -D bluetooth`.
  PCM `bluetooth` из `/etc/asound-bluetooth.conf` устроен как `softvol` поверх `speakers` со
  своим регулятором `Bluetooth Master Playback Volume` (от −51 до 0 дБ).
- **Свой звук** в WAV играет `aplay` в ALSA `default`. Звук идет в тот же `dmix`, что и у
  Алисы, и громкость у них общая:

    ```sh
    aplay /data/sounds/my.wav
    ```

- Модуль `snd-aloop.ko` входит в прошивку:
  `/lib/modules/4.9.68/kernel/sound/drivers/snd-aloop.ko`. Загрузку не проверяли.

`pcm.!default` в `/etc/asound.conf` разделяет направления. Воспроизведение идет в
`speakers`, это `plug` поверх `dmix_speakers` (`ipc_key 1024`, `hw:0,0`, 2 канала, 48 кГц).
Захват идет из `multi_capture`:

| Канал `hw:0,1` | Что в нем |
|---|---|
| 0, 1, 2 | микрофоны PDM0–PDM2 |
| 6 | `HW feedback (TDMB_IN0)`: то, что уходит на усилитель, опора для эхоподавления |

**Системные звуки** лежат в `/system/vendor/quasar/sounds/`: `common/` (17 файлов) и
`ru-RU/` (23 фразы). Еще 14 файлов лежат в `/data/quasar/data/sounds/ru-RU/`, среди них
`seam_activation_feedback_1…9.mp3` и `vins_error.wav`. Форматы в `common/` по заголовкам
файлов:

| Файл | Формат |
|---|---|
| `bluetooth_turning_{on,off}_jingle.opus` | Ogg Opus |
| `calls_*.mp3`, `notification_sound.mp3`, `volume_sound.mp3` | MP3 |
| `spotter_start.mp3`, `spotter_cancel.mp3`, `qc_buttons_test.mp3` | MP3 |
| `timer.wav` | **MP3** (расширение `.wav`) |

## Вход { #input }

- `/dev/input/event1` `aw933xx`: сенсорные кнопки. Коды клавиш `KEY_VOLUMEDOWN` 114,
  `KEY_VOLUMEUP` 115, `KEY_VOICECOMMAND` 582, как на Мини 2.
- `/dev/input/event0` `gpio-keys`: кнопка выключения микрофонов на задней стенке, прямо над
  разъемом USB Type-C. Отдает клавишу `KEY_MUTE` 113 и переключатель `SW_MUTE_DEVICE`.
- Микрофоны: три PDM. В `quasar.cfg` у `audiod` стоят `micChannels: 3`, `spkChannels: 1`,
  захват 48 кГц. Основной канал (`mainChannel`) у него `vqe_0`: 16 кГц после Yandex VQE с
  пресетом `bergamot`.
- Споттеры в `quasar.cfg`: `activation/alisa` (модель собрана под bergamot),
  `activation/yandex`, `activation/yasmina` (ar-SA), `command`, `counteractivation`,
  `intonationInterruption` и `vad`.
- Датчик освещенности LTR-308 (`1-0x53`) виден как `iio:device1`.

# Станция Стрит

Розничное имя — **Яндекс Станция Стрит** (портативная, с аккумулятором); кодовое имя —
**Mango** (device-tree `Yandex Station Mango DVT`, **`amlogic,a1`**). Отдельная,
самая «лёгкая» платформа в семействе: SoC **Amlogic A1** (дешёвый IoT-чип), **32-битное
ядро** и ядра **Cortex-A35**. Главная особенность — **встроенный аккумулятор** и
зарядка по USB-C.

Прошивка — Buildroot + quasar/maind, но учитывайте 32-битность и ядро 5.15.

## Платформа в двух словах { #platform }

| Что | Значение |
|---|---|
| SoC | **Amlogic A1** (`amlogic,a1`) |
| CPU | 2× **Cortex-A35** (`0xd04`), до **1.2 ГГц** (128…1200 МГц) |
| Разрядность | **armv7l (32-бит)** — ядро и userspace 32-битные (ARMv7, `CPU architecture 7`) |
| ОЗУ | **~226 МБ** (MemTotal 226116 kB) |
| Флеш | NAND, UBI поверх MTD |
| Ядро | Linux **5.15.137** armv7l (сборка 20260918) |
| Userspace | Buildroot **2023.11.1** |
| Питание | **аккумулятор** — датчик заряда **CW2217**, зарядник **charge2366** |
| Усилитель | **ACM8625** (`snd_soc_acm8625`) |
| Акселерометр | **SC7A20E** (`1-0x19`) — ориентация/тряска |
| Индикация | логотип (3 зоны RGBW) + индикатор заряда (4 красных) |
| Радио | **Unisoc** (`vlsicomm` + `aml_sdio` + `sdio_bt`), BT-пульт |
| quasar | 3.21 (`0.368.1.5.4669831238.20260918`) |

!!! info "Единственная модель на 32-битном ядре и со встроенным аккумулятором"
    - **Единственная на 32-битном ядре** (`armv7l`) и на SoC **Amlogic A1** —
      остальные Станции 64-битные.
    - **Портативная с аккумулятором** → есть контроллер заряда, топливомер и
      отдельные LED-индикаторы заряда.
    - **Акселерометр** (ориентация/жесты) — для переносного корпуса.

## Получение root { #root }

Основной способ — **[подмена DNS](../start/root.md)**: сброс колонки, свой DNS на роутере,
дальше сетевой ADB. На Стрит проверен. После него — [SSH и отключение
обновлений](../start/ssh.md).

Ядро здесь 32-битное, поэтому пакеты и демоны под `aarch64` не запустятся.

После перезагрузки ADB поднимается сам, но заметно дольше обычного — не стоит
считать, что он не стартует, если он не отвечает первые минуты.

!!! warning "Сразу после сброса колонка сама ставит свежую прошивку"
    Сброс загружает заводской образ `0.11.1.9…factory-11`. Через пару минут после
    привязки колонка скачивает актуальную прошивку и записывает её
    (`device_ota_update.sh`), затем перезагружается. Не выключайте колонку, пока идёт
    запись: прерывание может оставить её без системы. Root переживает это обновление:
    маркеры ADB лежат в `/data`. Сразу после перезагрузки [отключите
    обновления](../start/ssh.md#kill-ota).

    Проверено на Станции Стрит: заводской `factory-11` → `0.373.1.16`, ноябрь 2026.

## Разделы флеша { #partitions }

```text
mtd0 "bootloader" 2 MB    mtd1 "tpl" 8 MB     mtd2 "tee" 1 MB -> /tee (jffs2, RO)
mtd3 "recovery" 50 MB     mtd4 "boot" 12 MB
mtd5 "system" 80 MB -> ubi0:rootfs (ubifs, RO)
mtd6 "bkupgrade" 97 MB -> ubi1 (RW) = /bkupgrade
```

rootfs — ubifs **RO** (`assert=read-only`); `/tee` — **jffs2** на отдельном разделе
`tee` (не на `nv`, как у AXG-моделей). `/var/lib/bluealsa` вынесен на ubi1.

!!! note "Анимация логотипа запускается по I2C до старта системы"
    Её включает `i2c-animation.run=preboot-logo` в cmdline.

## Шина I2C и периферия { #i2c }

| Шина:адрес | Чип | Назначение |
|---|---|---|
| `1-0x19` | **SC7A20E** (sc7a20e_acc) | акселерометр |
| `1-0x20` | **AW21012** | LED-драйвер (матрица) |
| `1-0x2c` | **ACM8625** (acm8625s) | Class-D усилитель |
| `1-0x51…0x57` | 24C02 | EEPROM (несколько) |
| `1-0x5b` | **AW9110** | LED/GPIO-экспандер |
| `1-0x64` | **CW2217** (cw2217) | топливомер аккумулятора |
| `1-0x75` | **charge2366** | контроллер зарядки |

## Индикация { #led }

Все узлы в `/sys/class/leds/`:

- **Логотип:** `mango:{red,green,blue,white}:logo0..2` — 3 зоны, каждая RGBW.
- **Индикатор заряда:** `mango:red:charge0..3` — 4 красных сегмента + `mango:charge:sync`.

Драйверы: `leds_aw2101x`, `leds_aw9110`, подсистема `quasar_led_ring`.

### Управление из своих скриптов

Чтобы управлять светодиодом самому, сначала отключите штатный триггер
(`echo none > /sys/class/leds/<узел>/trigger`), потом пишите яркость в `brightness`.
Штатные триггеры, которые нужно вернуть обратно после своих экспериментов:
`ledfb-logo` (логотип), `ledfb-charge` (индикатор заряда), `ledfb-charge-sync`.
Рабочий вариант — небольшой сервис, который по SSH пишет в `/sys/class/leds/mango:*`
и умеет возвращать триггеры.

## Звук { #audio }

- ALSA card0 `AML-AUGESOUND`: `TDM-B-acm8625` (усилитель), `PDM` (микрофоны),
  `LOOPBACK-A` (AEC). Усилитель — **ACM8625**.
- Устройство `plughw:0,1` (acm8625) в простое свободно, тестовый звук через `aplay`
  играет. Микшер — `Master`.

### Свои звуки { #sounds }

Системные звуки Алисы лежат в `/system/vendor/quasar/sounds/common`. Каталог `/system`
находится на корневой ФС (`ubi0:rootfs`, смонтирована `ro`), отдельного раздела нет,
поэтому для замены нужен временный ремаунт корня:

```sh
mount -o remount,rw /
# заменить файлы, права 644
mount -o remount,ro /
```

Оригиналы сохраните заранее. Замена большинства звуков через ADB проверена.
Подробнее — [Свои звуки](../recipes/sounds.md).

## AirPlay и Spotify Connect { #spotiya }

Оба варианта проверены через проект [spotiya](https://github.com/klockky/spotiya)
(быстрая установка из README). Он ставится в `/data/opt/spotify-connect`, автозапуск —
`/etc/init.d/S99spotify-connect`, команда `/usr/bin/spotiya` — ссылка на `cli.sh`
в том же каталоге. В `profiles/` лежат `generic.json`, `mini1.json`, `mini2.json`
и `street.json`. Профиль Стрит минимальный:

```json
{
  "version": 1,
  "id": "street",
  "name": "Yandex Station Street",
  "audio": {
    "device": "plughw:0,1",
    "format": "S16",
    "mixer_device": "hw:0",
    "mixer_control": "Master",
    "mixer_index": 0,
    "mixer_channel": "mono"
  },
  "voice": null,
  "controls": null
}
```

Вывод идёт на `plughw:0,1`, громкость — через микшер `Master`. Разделы `voice` и
`controls` не настроены.

- **AirPlay** работает (проверено с iPhone 11), звук и громкость нормальные. Штатная
  подсветка при этом реагирует на музыку так же, как на звук Алисы. Службы AirPlay
  запустились только после добавления группы `nogroup` в `/etc/group`
  (строка `nogroup:x:65534:`).
- **Spotify Connect**: вход по коду на аккаунте без Premium не прошёл
  (`session validation failed`). С Premium не проверялось.

## Вход { #input }

События читаются из `/dev/input/eventN`. Номера могут сместиться, поэтому в скриптах
находите устройство по имени из `/proc/bus/input/devices`.

| Устройство | Событие | Что умеет |
|---|---|---|
| `gpio_keypad` | `event0` | `KEY_MUTE` (113), `KEY_POWER` (116), переключатель `SW_MUTE_DEVICE` (14) |
| `accel` | `event1` | акселерометр (оси ABS), кнопок нет |
| `input_btrcu` | `event2` | Bluetooth-пульт (`KEY_POWER`, код 133), не проверялось |
| `adc_keypad` | `event3` | кнопки громкости, паузы, Bluetooth и Алисы |

Кнопки, проверенные вживую:

| Кнопка | Код | Константа | Устройство |
|---|---|---|---|
| Громкость + | 115 | `KEY_VOLUMEUP` | `adc_keypad` |
| Громкость − | 114 | `KEY_VOLUMEDOWN` | `adc_keypad` |
| Пауза/плей | 119 | `KEY_PAUSE` | `adc_keypad` |
| Bluetooth | 237 | `KEY_BLUETOOTH` | `adc_keypad` |
| Алиса | 582 | `KEY_VOICECOMMAND` | `adc_keypad` |
| Микрофон | 113 | `KEY_MUTE` | `gpio_keypad` |
| Питание | 116 | `KEY_POWER` | `gpio_keypad` |

Кнопка микрофона с запоминаемым состоянием: на каждое нажатие приходит `KEY_MUTE`
(нажато, затем отпущено) и между ними `SW_MUTE_DEVICE` (`1` — микрофон выключен,
`0` — включён).

### Как прочитать события без evtest

Если `evtest` недоступен, события читаются сырыми байтами. На 32-битном ядре одно событие
занимает 16 байт: 8 байт время, 2 байта тип, 2 байта код, 4 байта значение.

```sh
od -An -tx1 -w16 -v /dev/input/event3
```

В каждой строке байты 9–10 — тип (`01 00` клавиша, `05 00` переключатель, `00 00` — `SYN`,
его можно игнорировать), байты 11–12 — код (little-endian, например `73 00` = 115),
байт 13 — значение (`01` нажато, `00` отпущено).

### Акселерометр

Текущее значение читается из `/sys/devices/virtual/input/input1/value` — одна строка
вида `X Y Z`. Период опроса в sysfs — `delay` = 200 мс. На этом можно построить,
например, 3D-визуализацию положения колонки: данные снимаются по постоянному
`adb shell`.

# Умный хаб Яндекса

Розничное имя — **Умный хаб Яндекса** (Yandex Smart Home Hub); кодовое имя —
**Saturn** (device-tree `Yandex Saturn`, `yandex,saturn` / `amlogic, axg`). Это **не
колонка**: устройство без динамика и микрофонов, выделенный **хаб умного дома** —
мост **Zigbee + Bluetooth + ИК** к экосистеме Яндекса. Платформа при этом та же
Amlogic AXG + Buildroot + quasar, поэтому приёмы доступа/прошивки общие.

!!! info "Почему он в этой вики"
    Хаб построен на той же quasar-платформе, что и Станции (тот же `maind`, те же
    механизмы доступа и OTA), и интересен сообществу теми же методами. Главное
    отличие по железу — **нет аудиотракта**, зато есть ИК-приёмопередатчик и Zigbee.

## Платформа в двух словах

| | |
|---|---|
| SoC | **Amlogic AXG** (`amlogic, axg`) |
| CPU | 4× Cortex-A53 (`0xd03`), до **1.2 ГГц** |
| ОЗУ | **~244 МБ** (MemTotal 243920 kB) |
| Флеш | NAND, UBI поверх MTD (разметка как у минислушателей) |
| Ядро | Linux **4.9.68** aarch64 (сборка 20260924) |
| Userspace | Buildroot **2020.02.1** |
| Аудио | **нет** (ни звуковых карт, ни PCM, ни микрофонов) |
| Умный дом | **Zigbee** (`zigbee_control`) + **Bluetooth** (`sdio_bt`) |
| ИК | **приём и передача** (`meson-ir` + `meson-ir-tx`) — универсальный пульт/бластер |
| Индикация | один RGB-светодиод статуса (`saturn:{red,green,blue}:main`, `leds_pwm`) |
| Звуковой сигнал | **pwm-beeper** (пищалка) |
| RTC | **PCF8563** (`0-0x51`) |
| Радио | **Unisoc** (`vlsicomm` + `aml_sdio` + `sdio_bt`) |
| quasar | 3.21 (`0.369.1.0.4698823002.20260924`), роль только `--platformd` |

## Чем отличается от Станций

- **Нет аудио вообще** — `## sound cards` пуст (`--- no soundcards ---`), PCM нет,
  микрофонов нет. Это чистый хаб, не колонка.
- **ИК-приёмопередатчик** `meson-ir` (RX) + `meson-ir-tx` (TX) — может **принимать и
  отправлять** инфракрасные команды (управление телевизорами/кондиционерами как
  ИК-бластер).
- **Zigbee** (`zigbee_control`) + **Bluetooth** — радиомосты умного дома.
- **pwm-beeper** — звуковой сигнал (вместо динамика).
- Минимальная индикация — **один RGB-светодиод** статуса (PWM, `leds_pwm`), без
  кольца/дисплея.
- quasar запускает только **`--platformd`** (нет `--mediad` — воспроизводить нечего).

## Карта флеша (MTD)

```text
mtd0 "bootloader" 2 MB   mtd1 "tpl" 2 MB    mtd2 "boot" 10 MB
mtd3 "system" 80 MB -> ubi0:rootfs (ubifs, RO)
mtd4 "nv" 1 MB     mtd5 "bkupgrade" ~105 MB -> ubi1 (RW) = /bkupgrade
mtd6 "recovery" 50 MB
```

Разметка идентична минислушателям на AXG (256 МБ NAND, UBI). rootfs — ubifs **RO**.

## Шина I2C и периферия

| Шина:адрес | Чип | Назначение |
|---|---|---|
| `0-0x50` | 24C02 | EEPROM (заводские данные) |
| `0-0x51` | **PCF8563** | RTC |

(Остальная периферия — Zigbee/ИК/beeper/LED — не на I2C, а через SoC-блоки и GPIO.)

## Вход / выход

- `meson-ir` — приём ИК (обучение с пультов).
- `meson-ir-tx` — передача ИК (эмуляция пультов).
- `pwm-beeper` — звуковой сигнал.
- `gpio-keys` — кнопка(и).

## Идеи / что проверить

- **ИК-бластер из своих скриптов:** доступ к `meson-ir-tx` (`/dev/lirc*` или sysfs) —
  слать произвольные ИК-коды (управление ТВ/кондиционером помимо Яндекса).
- **Обучение ИК:** снимать коды с пультов через `meson-ir`.
- **Zigbee-координатор:** что за радиочип за `zigbee_control`, можно ли использовать
  как обычный Zigbee-coordinator (Z2M/ZHA).
- Отключение OTA и durable-доступ — по общей схеме [Платформы](../start/root.md).

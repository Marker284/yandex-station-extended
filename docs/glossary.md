# Словарь

Слова, которые встречаются в инструкциях. Если в тексте попалось что-то непонятное —
скорее всего, оно здесь.

## Доступ к колонке { #access }

**Root** — полные права в системе колонки. С ними можно зайти по SSH, ставить свои
программы и править системные файлы. Без root колонка остаётся закрытой коробкой.
Как его получить — [с чего начать](start/index.md#root-by-model).

**ADB** (Android Debug Bridge) — утилита, которой компьютер управляет колонкой по сети
или по кабелю. Первое, что ставят на компьютер, — [установка ADB](start/adb.md).

**SSH** — обычный способ зайти в консоль устройства по сети. На колонке его поднимает
[dropbear](start/ssh.md), маленький SSH-сервер; вход идёт на порт 2222.

**Маркеры ADB** — пустые файлы в `/data/quasar`, по которым прошивка при загрузке решает,
включать ли ADB по сети. Пропадают при сбросе, поэтому их защищают от удаления.

## Как колонку открывают { #methods }

**DNS** — служба, которая превращает имя сайта в адрес сервера. Какой DNS спрашивать,
устройству сообщает роутер, поэтому через роутер колонке можно подсунуть свой ответ.

**Подмена DNS** (DNS-метод) — основной способ. Колонку сбрасывают, и при настройке её
запросы к серверам Яндекса уводят на другой адрес, откуда приходит ответ, включающий ADB.
Нужен роутер, в котором можно задать свой DNS. [Инструкция](start/root.md).

**Сервер разблокировки** — чужой готовый сервер, который отвечает колонке вместо Яндекса;
в инструкциях это адрес `179.254.167.126`. Если такой сервер поднимают у себя, его называют
**своим сервером обновлений на компьютере** — он делает то же самое, но ничего не знает
о вас.

**eQuasar** — готовый сервер, который отвечает колонке вместо Яндекса: запускается на
компьютере, раздаёт нужный ответ на проверку обновлений и проксирует остальное в облако.
Нужен в способах с подменой сертификата.

**Сервисный режим** (factory mode) — особый режим загрузки, в который колонка попадает,
если включить её с зажатой кнопкой. В нём работает заводская сборка, у которой другие
правила доверия, — на этом основан способ с [подменой сертификата](start/retail-ca.md).

**CA-бандл** — файл со списком удостоверяющих центров, которым колонка доверяет. Пока
нужного центра в списке нет, колонка не станет разговаривать с чужим сервером по HTTPS.

**AliceBridge** — приложение для Android-телефона с root: раздаёт колонке Wi-Fi и делает
всё само, без компьютера. [Инструкция](start/root-android.md).

**Shell, консоль колонки** — окно, в котором команды выполняются **внутри** колонки.
Туда попадают командой `adb shell` или по SSH; выход — `exit`. Пока вы в shell,
приглашение меняется, и команды компьютера там уже не работают.

**WSL** — Linux внутри Windows. Ставится командой `wsl --install` в PowerShell от
администратора и даёт обычный Linux-терминал, где работают команды из инструкций.

## Прошивка и её части { #firmware }

**Прошивка, сборка** — версия системы колонки, например `0.369.1.50.4794654278.20261021.133`.
Способы получения root зависят от сборки: после обновления 21 октября 2026 года часть из них
перестала работать.

**OTA** — обновление «по воздуху», которое Яндекс присылает сам. После получения root его
[отключают](start/ssh.md#kill-ota), иначе доступ пропадёт.

**Quasar** — программный стек Яндекса на колонке: активация, Алиса, музыка, обновления.
Главный процесс называется `maind`, [разбор](internals/architecture.md).

**Buildroot** — способ сборки маленьких Linux-систем. На Станциях на Amlogic система
собрана им, поэтому там нет привычных пакетных менеджеров и systemd.

**rootfs, корневая файловая система** — системный раздел, тот самый `/`. По умолчанию
только для чтения; чтобы что-то записать, его временно перемонтируют командой
`mount -o remount,rw /`.

**`/data`** — раздел с пользовательскими данными. Переживает обновления и перезагрузки,
но стирается при сбросе к заводским настройкам. Свой софт кладут в `/data/opt`: на части
моделей это единственное место, где правки точно сохранятся.

**Том UBI** — раздел внутри UBI, у него есть имя: например `rootfs`. Адресуется как
`ubi0:rootfs`, где `ubi0` — номер подключённого устройства UBI.

**MTD, UBI, eMMC** — как устроена память колонки. MTD — «сырые» разделы флеш-памяти,
UBI — слой поверх неё, eMMC — память с собственным контроллером, как в телефонах.
У каждой модели своё, см. [каталог устройств](devices/index.md).

## Софт на колонке { #software }

**Entware** — репозиторий готовых программ для устройств на ARM: `htop`, `python`, `git`
и ещё тысячи. Ставится в `/data/opt` и не трогает систему.

**yse** — скрипт из этой вики, который ставит пакеты из Entware и из реестров `.yap`.
[Шаг 3](start/packages.md).

**`.yap`** — формат готовой сборки программы под Станции. Реестр таких пакетов лежит
на GitHub, оттуда их и берёт `yse`.

**YAM** — сторонний менеджер плагинов с веб-панелью и доступом к железу колонки:
подсветке, кнопкам, датчикам. [Рецепт](recipes/packagemanagers.md).

## Остальное { #misc }

**uniproxy** — соединение, по которому колонка передаёт голос в облако и получает ответ.
Его адрес подменяют, [заменяя Алису своей моделью](recipes/llm.md), — но не во всех
способах: голосовой режим ChatGPT работает со звуком прямо на колонке и этот адрес
не трогает.

**Кирпич** — состояние, когда колонка не включается и не отвечает ни по сети, ни по USB.
Из него вики вытащить пока не умеет, поэтому системные разделы правят осторожно.

**Factory-образ** — заводская сборка, которая лежит в отдельном разделе памяти и
запускается в сервисном режиме. Она старая, и правила доверия у неё мягче.

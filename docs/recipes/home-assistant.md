# Лайт 2 как голосовой спутник Home Assistant

[Pulsar][pulsar] подключает микрофоны и динамик Лайт 2 к голосовому ассистенту Home Assistant,
далее HA. Обработку запросов и голос выбирают в настройках Assist.

**Проверено на:** Станция Лайт 2 (Plum), прошивка
`0.369.1.50.4794654278.20261021.133`, Pulsar 0.5.0, HA Core 2026.9.2, Linux x86-64,
28 октября 2026. Голосовой ответ и автозапуск проверены после перезагрузки.

!!! warning "Меняется запуск колонки"
    Pulsar останавливает штатную Алису, а автозапуск добавляет файл в системный раздел.
    Сохраните резервные копии и до установки проверьте
    [совместимость с другими рецептами](#compatibility).

## Что понадобится { #requirements }

- Лайт 2 с уже полученным [root](../start/retail-ca.md) и настроенным
  [SSH на порту 2222](../start/ssh.md#dropbear).
- Компьютер с Linux, macOS или Windows с WSL2; OpenSSH, curl, tar и OpenSSL.
- Работающий Home Assistant с интеграцией ESPHome и доступом к колонке по локальной сети.
- Настроенный в HA ассистент с распознаванием и синтезом речи на русском.
- Резервная копия HA и сохранённая вне колонки
  [копия системных файлов из `/data/opt/backup`](../start/ssh.md#kill-ota).

Инструкция рассчитана на первую установку. Если каталог Pulsar или его автозапуск уже есть,
используйте [обновление установленного Pulsar][pulsar-control], не перезаписывайте их по этому
рецепту. Штатные обновления Яндекса должны быть отключены на
[этапе закрепления доступа](../start/ssh.md); Pulsar сам их не блокирует.

## Установка { #install }

### Проверьте ассистента в HA { #assist }

1. В **Настройки → Голосовые ассистенты** выберите уже настроенного ассистента с русским языком.
2. Убедитесь, что у него выбраны агент обработки запросов, распознавание и синтез речи.
3. Проверьте ответ через Assist до подключения колонки. Используйте запрос, который понимает
   выбранный агент.

Если готового ассистента нет, сначала настройте его по [официальной инструкции HA][ha-voice].
Pulsar использует выбранного в HA агента; отдельная модель на колонку не устанавливается.

### Скопируйте Pulsar по SSH { #copy }

Все команды выполняются на компьютере в одной оболочке. В Windows используйте терминал
Linux-дистрибутива WSL2. Задайте адрес своей колонки:

```sh
station_ip='<STATION_IP>'
```

Порт 2222 соответствует [настройке Dropbear из вики](../start/ssh.md#dropbear).
При входе с пустым паролем на каждый запрос пароля нажимайте Enter. Если SSH у вас настроен
на другом порту, замените 2222 в командах.

1. На компьютере создайте отдельный каталог для файлов установки:

    ```sh
    mkdir pulsar-lite2
    cd pulsar-lite2
    ```

2. Выберите [архив релиза 0.5.0][release] для своего компьютера:

    | Компьютер | Архив |
    |---|---|
    | Linux x86-64 или WSL2 x86-64 | `pulsar-linux-amd64.tar.gz` |
    | Linux ARM64 или WSL2 ARM64 | `pulsar-linux-arm64.tar.gz` |
    | macOS, Intel | `pulsar-macos-amd64.tar.gz` |
    | macOS, Apple Silicon | `pulsar-macos-arm64.tar.gz` |

    Подставьте имя из таблицы и скачайте архив:

    ```sh
    archive_name='<ARCHIVE_NAME>'
    curl -fLO "https://github.com/Morvex885/pulsar/releases/download/v0.5.0/$archive_name"
    ```

3. Распакуйте архив:

    ```sh
    tar -xzf "$archive_name"
    ```

4. Убедитесь, что это первая установка:

    ```sh
    ssh -p 2222 "root@$station_ip" 'test ! -e /data/pulsar && test ! -e /etc/init.d/S99zpulsar'
    ```

    Если команда завершилась ошибкой, остановитесь и проверьте существующую установку.

5. Создайте каталог на колонке:

    ```sh
    ssh -p 2222 "root@$station_ip" 'umask 077; mkdir /data/pulsar'
    ```

6. Передайте программу и скрипты из архива:

    ```sh
    ssh -p 2222 "root@$station_ip" 'cat > /data/pulsar/pulsar' < pulsar/satellite/build/armhf/pulsar
    for part in boot.sh supervise.sh ctl.sh; do
        ssh -p 2222 "root@$station_ip" "cat > /data/pulsar/$part" \
            < "pulsar/satellite/deploy/$part" || break
    done
    ```

    Если передача любого файла не удалась, не переходите к запуску.
    На Лайт 2 нужна сборка `armhf`: её пользовательская среда 32-битная,
    хотя ядро сообщает `aarch64`.

7. Подготовьте ключ шифрования до первого запуска:

    ```sh
    (umask 077; openssl rand -base64 32 > api_key)
    ssh -p 2222 "root@$station_ip" 'umask 077; cat > /data/pulsar/api_key' < api_key
    ```

    Сохраните файл `api_key`: его содержимое понадобится при добавлении ESPHome в HA.
    Ключ даёт доступ к микрофону и управлению колонкой, не публикуйте его.

8. Разрешите выполнение файлов:

    ```sh
    ssh -p 2222 "root@$station_ip" 'chmod 755 /data/pulsar/pulsar /data/pulsar/*.sh'
    ```

9. Включите Pulsar:

    ```sh
    ssh -p 2222 "root@$station_ip" '/data/pulsar/ctl.sh enable'
    ```

    С этого момента штатная Алиса остановлена. Для возврата используйте [откат](#rollback).

### Подключите колонку к HA { #pair }

1. В **Настройки → Устройства и службы** добавьте обнаруженное устройство ESPHome.
   Если его нет, добавьте интеграцию ESPHome вручную: адрес колонки, порт 6053.
2. При запросе ключа шифрования введите содержимое сохранённого файла `api_key`.
3. На странице устройства выберите подготовленного ассистента и фразу активации «Алиса».
4. Если микрофон выключен, включите его кнопкой на корпусе.
5. Скажите «Алиса», дождитесь сигнала и задайте вопрос, который понимает выбранный агент.
6. На странице устройства оставьте переключатель **Auto update** выключенным, чтобы сохранить
   проверенную версию Pulsar.

В HA появится голосовой спутник Assist satellite, а ответ прозвучит из колонки.
Если нужен доступ к свету и другим устройствам, отдельно
[разрешите их для Assist][ha-expose].

### Добавьте автозапуск { #autostart }

После успешного ответа создайте на компьютере отдельный скрипт автозапуска:

```sh
cat > S99zpulsar <<'SH'
#!/bin/sh
[ "$1" = start ] || exit 0
/data/pulsar/boot.sh &
SH
```

Передайте скрипт на колонку:

```sh
ssh -p 2222 "root@$station_ip" 'cat > /data/pulsar/S99zpulsar' < S99zpulsar
```

Установите его в системный раздел. Этот блок предназначен для проверенной прошивки Лайт 2;
он не заменяет исходный запуск Quasar или существующий автозапуск SSH:

```sh
ssh -p 2222 "root@$station_ip" 'sh -s' <<'SH'
set -eu
[ ! -e /etc/init.d/S99zpulsar ]
sh -n /data/pulsar/S99zpulsar
mount -o remount,rw /
trap 'mount -o remount,ro /' EXIT
cp /data/pulsar/S99zpulsar /etc/init.d/S99zpulsar
chmod 755 /etc/init.d/S99zpulsar
sync
SH
```

Перезагрузите колонку, когда её можно ненадолго отключить:

```sh
ssh -p 2222 "root@$station_ip" reboot
```

SSH-соединение оборвётся. После загрузки проверьте повторное подключение и состояние Pulsar:

```sh
ssh -p 2222 "root@$station_ip" '/data/pulsar/ctl.sh status'
```

Ожидается режим pulsar и работающий процесс. Устройство должно вернуться в HA,
а повторный голосовой вопрос получить ответ.

## Использование { #usage }

Фраза «Алиса» запускает выбранного ассистента HA. Распознавание, агент и озвучка
заменяются в его настройках, без повторной установки Pulsar. Home Assistant и службы
выбранного ассистента должны оставаться включёнными; компьютер, с которого копировали
файлы, можно выключить, если эти службы работают на другой машине.

## Если не получилось { #troubleshooting }

| Симптом | Что проверить |
|---|---|
| Колонка не появилась в HA | Добавьте ESPHome вручную по IP и порту 6053; проверьте доступ между HA и колонкой. |
| HA запрашивает ключ | Введите тот же `api_key`, который передали на колонку; не удаляйте ключ для обхода ошибки. |
| Микрофон не реагирует | Проверьте кнопку микрофона и состояние микрофона на странице устройства. |
| Колонка слышит обращение, но не отвечает | Проверьте выбранного ассистента, доступность распознавания и синтеза речи, журнал Assist. |
| Программа не запускается | Убедитесь, что скопирована сборка `armhf`. При подозрении на повреждённый файл выполните [дополнительную проверку](#checksums). |
| После перезагрузки вернулась Алиса | Проверьте наличие и права `S99zpulsar`, затем журнал Pulsar. |

Прочитайте состояние и последние строки журнала по SSH:

```sh
ssh -p 2222 "root@$station_ip" '/data/pulsar/ctl.sh status'
ssh -p 2222 "root@$station_ip" '/data/pulsar/ctl.sh log 50'
```

### Проверка файлов { #checksums }

??? tip "Если архив не распаковывается или программа не запускается"
    Можно сверить контрольные суммы, чтобы проверить скачивание и копирование файлов.
    Команды ниже одинаковы для Linux, macOS и WSL2. Выполняйте их в каталоге установки.
    Если открыли новый терминал, снова задайте `archive_name` и `station_ip`,
    как в [шаге установки](#copy).

    Вычислите сумму скачанного архива:

    ```sh
    openssl dgst -sha256 "$archive_name"
    ```

    Сравните её со строкой своего архива в [списке контрольных сумм релиза][checksums].
    Если значения различаются, скачайте архив заново.

    Для проверки копирования сравните суммы программы на компьютере и колонке:

    ```sh
    openssl dgst -sha256 pulsar/satellite/build/armhf/pulsar
    ssh -p 2222 "root@$station_ip" 'sha256sum /data/pulsar/pulsar'
    ```

    Сравнивайте сами значения хеша: имена файлов и оформление вывода могут различаться.
    Если суммы не совпали, повторите передачу программы.

## Ограничения { #limits }

- Установка на колонку проверена с Linux x86-64. Для macOS и WSL2 приведены варианты
  команд, но полный проход с этих систем не выполнялся.
- Проверена одна Станция Лайт 2 (Plum) на указанной прошивке. Другие модели и версии
  в этом рецепте не проверялись.
- Штатные ответы Алисы, Яндекс Музыка и облачное управление домом Яндекса в режиме Pulsar
  не обслуживают запросы; их заменяют настроенные возможности HA.
- Локальная активация и обработка микрофонов используют библиотеки прошивки.
  Колонка сохраняет системные DNS/NTP и привязку к Яндексу. Полная сетевая изоляция
  от Яндекса этим рецептом не проверена.
- Whisper, встроенный агент Home Assistant и Piper допускают локальную обработку.
  Если в ассистенте выбраны облачная LLM или TTS, для них требуется интернет.
- Мастер установки Pulsar и обновление через HA этим рецептом не проверены.
  Автообновление Pulsar оставлено выключенным. Защита от обновлений Яндекса настраивается
  [отдельно](../start/ssh.md#kill-ota).

### Совместимость с другими рецептами { #compatibility }

- [AirPlay на Лайт 2](airplay.md#lite2) использует [bt-proxy](bt-proxy.md) для связи
  со штатной Алисой. Эта связь требует работающего Quasar. Совместное воспроизведение
  AirPlay и Pulsar не проверялось; перед включением Pulsar остановите сторонние плееры.
- [ChatGPT Voice / Alisa Voice](llm.md#chatgpt-web) требует штатного Quasar и использует
  те же микрофоны и динамик. Перед запуском Pulsar остановите этот режим.
  Для возврата к нему сначала [выключите Pulsar](#rollback).
- [Quasar Bridge](llm.md#quasar-bridge) работает со штатным голосовым стеком.
  Настройка LLM через него не переносится в Assist; агент выбирается в HA.

## Откат { #rollback }

### Вернуть штатную Алису { #disable }

Выключите Pulsar, сохранив его файлы и настройки:

```sh
ssh -p 2222 "root@$station_ip" '/data/pulsar/ctl.sh disable'
```

Команда снимает признак включения Pulsar и запускает Quasar. Скрипт автозапуска при
следующей загрузке пропускает выключенный Pulsar. Сброс и перепрошивка не нужны.

Включить спутник HA снова:

```sh
ssh -p 2222 "root@$station_ip" '/data/pulsar/ctl.sh enable'
```

### Полностью удалить Pulsar { #uninstall }

Для первой установки по этому рецепту удалите также автозапуск и каталог программы.
Блок сначала возвращает Алису и проверяет совпадение автозапуска с сохранённой копией.
Если файл менялся, удаление остановится. Существующий SSH не удаляется.
Полное удаление на проверенной колонке не выполнялось.

```sh
ssh -p 2222 "root@$station_ip" 'sh -s' <<'SH'
set -eu
/data/pulsar/ctl.sh disable
cmp -s /data/pulsar/S99zpulsar /etc/init.d/S99zpulsar
mount -o remount,rw /
trap 'mount -o remount,ro /' EXIT
rm /etc/init.d/S99zpulsar
sync
mount -o remount,ro /
trap - EXIT
rm -rf /data/pulsar
SH
```

В HA удалите запись ESPHome этой колонки. Локальные файлы установки и файл `api_key`
на компьютере можно удалить, если повторная установка не нужна. После удаления каталога
Pulsar команда `enable` больше не работает; для возврата спутника потребуется установка.

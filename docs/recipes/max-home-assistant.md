# Станция Макс как голосовой спутник Home Assistant

[pulsar-max][pulsar-max] подключает Станцию Макс к Home Assistant, далее HA: колонка становится
голосовым спутником Assist и плеером Music Assistant. Слово «Алиса» распознаётся на колонке
моделью штатной Алисы, распознавание речи, агента и голос выбирают в настройках ассистента HA.
Проект основан на [Pulsar][pulsar], рецепт для Лайт 2 —
[Лайт 2 как голосовой спутник Home Assistant](home-assistant.md). Установка — около десяти минут.

**Проверено на:** Станция Макс с Zigbee (`YNDX-00052`), прошивка `5000000921`, `io.sdk`
3.367.25, pulsar-max 0.1.0, HA Core 2026.11.1, Music Assistant 2.10.11, ноябрь 2026.
Автозапуск и откат на прошлую версию проверены после перезагрузки.

!!! warning "Алиса перестаёт слышать, в `/odm` появляется файл"
    pulsar-max забирает микрофон у штатной Алисы и для автозапуска кладёт файл
    `/odm/etc/init/pulsar-max.rc`. Оба изменения снимает [откат](#rollback).

## Что понадобится { #requirements }

- Станция Макс с постоянным root и root-доступом по SSH на порту 2222. Известные способы —
  в разделе [«Постоянный рут»](root-max.md#permanent-root). Решение должно запускать
  init-сервисы из `/odm/etc/init` и после загрузки переводить SELinux в режим permissive.
- Компьютер с Linux, macOS или Windows с WSL2: `sh`, `ssh`, `curl` и `tar`.
- Работающий Home Assistant с интеграцией ESPHome.
- Настроенный в HA ассистент с распознаванием и синтезом речи на русском.
- Для музыки — Music Assistant 2.10.7 или новее.

## Установка { #install }

### Проверьте ассистента в HA { #assist }

1. В **Настройки → Голосовые ассистенты** выберите ассистента с русским языком.
2. Проверьте ответ через Assist до подключения колонки.

Если готового ассистента нет, сначала настройте его по [инструкции HA][ha-voice].

### Установите pulsar-max { #copy }

Все команды выполняются на компьютере в одной оболочке. Задайте адрес своей колонки:

```sh
station_ip='<STATION_IP>'
```

Если SSH на колонке слушает не порт 2222, задайте и его: `export PORT=<ПОРТ>`.

1. Скачайте [архив релиза 0.1.0][release] и контрольные суммы:

    ```sh
    base=https://github.com/nickspring/pulsar-max/releases/download/v0.1.0
    curl -fLO "$base/pulsar-max-v0.1.0.tar.gz" -fLO "$base/SHA256SUMS"
    ```

2. Проверьте архив:

    === "Linux и WSL2"

        ```sh
        sha256sum -c --ignore-missing SHA256SUMS
        ```

    === "macOS"

        ```sh
        shasum -a 256 -c --ignore-missing SHA256SUMS
        ```

    Ожидается `pulsar-max-v0.1.0.tar.gz: OK`. Если суммы не совпали, скачайте архив заново.

3. Распакуйте архив:

    ```sh
    tar -xzf pulsar-max-v0.1.0.tar.gz
    cd pulsar-max-v0.1.0
    ```

4. Запустите установщик:

    ```sh
    tools/install.sh "$station_ip"
    ```

    Установщик работает около минуты и в конце выводит состояние:

    ```text
    enabled
    version: pulsar-max v0.1.0
    supervisor: <PID>
    daemon: <PID>
    io.sdk microphone: RECORD_AUDIO: ignore
    ```

    С этого момента штатная Алиса не слышит микрофон. Если установщик закончил ошибкой,
    не запускайте его повторно — см. [«Если не получилось»](#troubleshooting).

### Подключите колонку к HA { #pair }

1. В **Настройки → Устройства и службы** добавьте обнаруженное устройство ESPHome
   «Яндекс Станция Макс». Если его нет, добавьте интеграцию ESPHome вручную: адрес колонки,
   порт 6053.
2. Ключ шифрования HA создаёт и передаёт колонке сам, вводить его не нужно.
3. На странице устройства выберите подготовленного ассистента.
4. Скажите «Алиса», дождитесь сигнала и задайте вопрос.

Ответ прозвучит из колонки. Доступ к свету и другим устройствам для Assist
[разрешается отдельно][ha-expose].

### Подключите Music Assistant { #music-assistant }

Колонка объявляет себя в сети Sendspin-плеером «Яндекс Станция Макс», Music Assistant находит
её сам. Music Assistant до 2.10.7 рукопожатие с колонкой не проходит (проверено на 2.10.2).

## Использование { #usage }

- «Алиса» или кнопка Алисы начинают диалог, повторное нажатие отменяет его. «Алиса»
  перебивает ответ и останавливает звонок таймера.
- Кнопка микрофонов запрещает диалог, в HA это видно по переключателю «Microphones».
- Щелчки крутилки меняют громкость колонки и приходят в HA событиями `volume_up` и
  `volume_down`.
- Короткие команды без «Алисы» и без HA: «стоп», «пауза», «продолжи», «громче», «тише»,
  «дальше», «назад». Полный список — в [README pulsar-max][commands].
- Кольцо показывает состояния голоса анимациями штатной Алисы, при музыке на экране —
  штатный эквалайзер.
- В настройках устройства в HA: стиль эквалайзера («Music visualization»), анимации кольца
  («Voice indication»), усиление микрофона («Microphone gain»). Настройки хранятся на
  колонке и переживают перезагрузку и обновление.

Распознавание, агент и голос меняются в настройках ассистента HA без переустановки
pulsar-max.

## Если не получилось { #troubleshooting }

| Симптом | Причина | Что делать |
|---|---|---|
| `not a Station Max: platform …` | установщик запущен не для Станции Макс | проверьте адрес колонки |
| `ssh does not give root` | SSH пускает не под root | проверьте способ постоянного root |
| `/odm did not go back to read-only` | `/odm` остался открыт на запись | выполните на колонке `mount -o ro,remount /odm` |
| `the daemon is not healthy` | программа падает при запуске | не запускайте установку повторно: после пяти падений колонка вернёт прошлую версию, а без неё — микрофон Алисе; прочитайте журнал |
| После перезагрузки отвечает Алиса | SELinux не перешёл в permissive за 5 минут, и pulsar-max вернул микрофон Алисе | проверьте `getenforce` и способ постоянного root |
| Колонка не появилась в HA | mDNS не доходит до HA | добавьте ESPHome вручную по адресу и порту 6053 |
| На телевизоре по HDMI запрос доступа к микрофону | приложение Яндекса просит микрофон обратно | не нажимайте «Разрешить», иначе оно снова начнёт падать каждые 10 минут |
| Music Assistant не подключает колонку | версия Music Assistant до 2.10.7 | обновите Music Assistant |

Состояние и последние строки журнала:

```sh
ssh -p 2222 "root@$station_ip" 'sh /data/pulsar-max/ctl.sh status'
ssh -p 2222 "root@$station_ip" 'sh /data/pulsar-max/ctl.sh log 50'
```

## Ограничения { #limits }

- Проверена одна Станция Макс с Zigbee (`YNDX-00052`) на прошивке `5000000921`. Обычная
  Станция Макс (`YNDX-0008`) и другие прошивки не проверялись.
- Штатные ответы Алисы, Яндекс Музыка и голосовое управление умным домом Яндекса не работают:
  микрофон у pulsar-max. Приложения Яндекса на колонке продолжают работать и выходить в сеть.
- Zigbee-радио остаётся у умного дома Яндекса, в HA оно не попадает: протокол прошивки
  радио ZHA и Zigbee2MQTT не понимают. Работа Zigbee-устройств
  Яндекса при включённом pulsar-max не проверялась.
- Ложные срабатывания «Алисы» и коротких команд на музыке, ТВ и длинных ответах HA не
  проверялись. Блокировки срабатываний на время своей речи, как у штатной Алисы, нет.
- Синхронность Music Assistant в группе с другими плеерами не проверялась.

## Откат { #rollback }

### Вернуть штатную Алису { #disable }

Выключите pulsar-max, сохранив его файлы и настройки:

```sh
ssh -p 2222 "root@$station_ip" 'sh /data/pulsar-max/ctl.sh disable'
```

Команда останавливает pulsar-max и возвращает микрофон Алисе. Автозапуск при следующей
загрузке выключенный pulsar-max пропускает. Включить снова:

```sh
ssh -p 2222 "root@$station_ip" 'sh /data/pulsar-max/ctl.sh enable'
```

### Вернуть прошлую версию { #previous }

После обновления прошлая версия остаётся на колонке:

```sh
ssh -p 2222 "root@$station_ip" 'sh /data/pulsar-max/ctl.sh rollback'
```

### Полностью удалить pulsar-max { #uninstall }

Из каталога распакованного архива:

```sh
tools/install.sh --uninstall "$station_ip"
```

Команда возвращает микрофон Алисе, удаляет программу и `/odm/etc/init/pulsar-max.rc`.
Ключи HA и Music Assistant и настройки остаются на колонке для повторной установки; удалить и
их — `tools/install.sh --uninstall --purge "$station_ip"`. Полное удаление на проверенной
колонке не выполнялось.

В HA удалите запись ESPHome этой колонки.

## Как это работает { #how }

- Звук с микрофонов pulsar-max берёт через Android `AudioRecord` уже после штатной обработки
  VQE, воспроизводит через AAudio и `MediaPlayer`.
- «Алиса» и короткие команды распознаются моделями штатной Алисы из приложения
  `com.yandex.io.sdk`, на колонке, без сети.
- У `io.sdk` отзывается разрешение на микрофон; `disable` и удаление возвращают его.
- Автозапуск — init-сервис из `/odm/etc/init`. Он ждёт режима permissive, затем запускает
  супервизор; после пяти падений подряд супервизор возвращает прошлую версию, а если нет
  и её — микрофон Алисе.

Разбор платформы и замеры — в [docs/max.md][max-md] проекта.

# MidiPult — веб-панель для Станции Миди

Панель [MidiPult](https://github.com/RoBiN19666/midipult) собирает управление
рутованной Станцией Миди в браузере телефона или компьютера: дисплей и кольцо,
музыка и радио, нейросеть, VPN, сценарии, файлы и обслуживание. Работает на самой
колонке — `lighttpd` и Python CGI на порту `8055`, без облака и внешних CDN.

**Проверено на:** Станция Миди (Cucumber), прошивка
`0.369.1.46.4778262955.20261013` (quasar 3.21, Buildroot 2023.11.1, ядро 5.4.180),
ноябрь 2026.

## Что понадобится { #requirements }

- root и SSH на колонке;
- Entware в `/opt`;
- около 20 МБ свободного места;
- браузер в той же локальной сети;
- для клиентов — открытый UDP-порт `8056`, иначе колонку добавляют по адресу.

Корень и Entware проект не устанавливает: установщик проверяет окружение и ставит
только недостающие пакеты Entware через `opkg`. Скриптов получения root в проекте
нет.

Luna нужна панели, но ставить её заранее не обязательно: установщик проверяет её и
при недоступности ставит проверенную сборку с проверкой SHA-256 и сохранением старой
копии. YAM не нужен.

## Установка { #install }

1. Склонируйте репозиторий на колонку или распакуйте архив релиза в `/tmp/midipult`:

    ```sh
    git clone https://github.com/RoBiN19666/midipult.git /tmp/midipult
    ```

    Если на колонке нет `git`, скачайте zip или tar.gz со
    [страницы релизов](https://github.com/RoBiN19666/midipult/releases) и распакуйте
    в `/tmp/midipult`.

2. Запустите установщик:

    ```sh
    cd /tmp/midipult
    sh deploy/install.sh
    ```

3. Откройте панель по адресу `http://<IP-колонки>:8055/`.

Установщик ставит недостающие пакеты Entware (`python3`, `lighttpd` с модулями CGI
и proxy, `curl`, `python3-websocket-client`), `ffmpeg`, создаёт автозапуск и
перезапускает службы. Модель он определяет по `/proc/device-tree/model`: на Станции
Миди и Станции 2 установка не отменяется, на остальных отменяется.

Проверка без установки пакетов и без правки Luna:

```sh
MYPULT_NO_PACKAGES=1 MYPULT_NO_BOOTSTRAP=1 sh deploy/preflight.sh
```

## Клиенты { #clients }

Оболочки для телефона и компьютера не содержат интерфейс панели: они находят
колонку в сети и открывают её панель во встроенном браузере. Поэтому панель и
клиент обновляются отдельно, а APK и установщик не нужно пересобирать после
каждого обновления панели.

- [MidiPult Android](https://github.com/RoBiN19666/midipult-android) — Android 6.0+,
  [APK](https://github.com/RoBiN19666/midipult-android/releases/latest): поиск
  колонок, карточки, меню и системный медиаплеер.
- [MidiPult Windows](https://github.com/RoBiN19666/midipult-windows) — Windows 10/11 x64,
  [установщик](https://github.com/RoBiN19666/midipult-windows/releases/latest): панель в
  WebView2, список колонок и портативный режим без установки.

## Использование { #usage }

Панель открывается в браузере телефона или компьютера в той же сети. Разделы:
«Главная», «Дисплей», «Звук», «Нейросеть», «Сеть», «Сценарии», «Настройки»,
«Система».

- **Главная:** 3D-модель станции с живым дисплеем и кольцом, цвет корпуса, карточка
  «Сейчас». Карточки двигаются и меняют размер.
- **Дисплей:** время станции, семисегментный редактор, анимации из кадров и бегущая
  строка до 32 символов. Набор только 7-сегментный: цифры, `_`, `-` и часть латинских
  букв, кириллицы нет. Автояркость настраивается кривой «освещённость → яркость».
- **Звук:** плеер с очередью и перемоткой, Яндекс Музыка со входом по QR, Сбер Звук,
  YouTube Music и SoundCloud с волной по настроению, текст песни для любого источника,
  29 встроенных радиостанций и свои каналы, будильники.
- **Нейросеть:** OpenAI, OpenRouter, DeepSeek, Anthropic и свой OpenAI-совместимый
  сервер; профили, поиск в интернете, чаты и озвучка ответов.
- **Сеть:** VPN sing-box по подписке, Wi-Fi, Bluetooth (приёмник A2DP и пульт по
  AVRCP), IPv6 и статус Zigbee.
- **Сценарии:** действия по фразе, расписание, условия, HTTP-запросы, свои звуки и
  анимации дисплея.
- **Настройки:** индикация панели, положение меню и раскладка с пресетами отдельно для
  компьютера, планшета и телефона, системные и свои звуки, PIN, голосовой пульт.
- **Система:** ресурсы и графики за сутки, характеристики, обновления, логи,
  обслуживание и проверка сети, бэкап, файлы, терминал, перезагрузка и выключение.

## Обновление { #update }

Панель обновляется из своего интерфейса: раз в сутки она проверяет GitHub Releases,
скачивает архив по HTTPS, сверяет SHA-256 и при ошибке откатывается. Кнопка
«Откатить обновление» возвращает последнюю резервную копию, а без интернета архив
можно поставить из файла.

## Безопасность { #security }

!!! warning "Порт 8055 нельзя выставлять в интернет"
    Панель работает по HTTP и выполняет CGI от root. PIN и проверка Origin защищают
    от чужих запросов в локальной сети, но трафик не шифруется.

- PIN по умолчанию выключен; после включения проверяется на сервере. Пять ошибок
  блокируют вход на пять минут, забытый PIN снимается удалением
  `/data/mypult/auth.json`.
- Терминал в «Системе» работает только при включённом PIN: сессия одна и закрывается
  после 15 минут простоя.
- `/luna/` не проксируется: Luna слушает только `127.0.0.1:8099`, а панель ходит к
  ней через `/cgi-bin/luna.py` после проверки PIN.
- Изменяющие действия принимаются только POST с того же origin; GET-ссылки их не
  запускают.
- CSP и `X-Frame-Options: DENY` включены.
- Ключи LLM, VPN и чаты лежат в `/data/mypult` с правами `600`; резервная копия
  содержит ключи.

## Ограничения { #limits }

- Проверено только на Станции Миди. На Станции 2 панель запускалась по сообщению
  одного пользователя, но после обновлений её там не перепроверяли.
- Голосовой пульт экспериментальный: Алиса может ответить раньше пульта, и «стоп»
  опаздывает. Обходы — текстовое поле, кнопки сценариев, физическая кнопка.
- Кнопка микрофона только запускает распознавание: фразу всё равно начинают с
  «Алиса». Своего распознавания без слова-обращения нет.
- Zigbee: панель показывает сеть и устройства, команды передаёт через Алису;
  полного локального управления нет.
- Музыка: Spotify не поддерживается (Web API не отдаёт аудио, нужен отдельный
  Spotify Connect), VK Музыки нет, Сбер Звук без токена даёт 30 секунд, YouTube Music
  идёт через `yt-dlp` и стартует несколько секунд.
- HTTPS, статический IP и установка PWA не реализованы: PWA — только ярлык на
  главный экран.
- Клиенты обновляются отдельно от панели; APK не содержит интерфейс панели.

## Откат { #rollback }

Установщик кладёт скрипт удаления в `/data/mypult/uninstall.sh`.

```sh
# показать план, ничего не меняя
sh /data/mypult/uninstall.sh --dry-run

# удалить панель и автозапуск, настройки оставить
sh /data/mypult/uninstall.sh

# удалить и /data/mypult с ключами и сценариями
sh /data/mypult/uninstall.sh --purge
```

`--yes` отключает подтверждение. Перед удалением скрипт делает бэкап в
`/data/mypult-uninstall-<дата>`, останавливает только процессы пульта и удаляет
`/data/myweb`, init-скрипты и конфиг lighttpd. Luna, YAM и Entware не затрагиваются,
перезагрузка не нужна. Бэкап остаётся и после `--purge`.

## Как это работает { #how }

`lighttpd` на `8055` отдаёт `index.html` и CGI на Python. CGI обращаются к Luna
(только `127.0.0.1:8099`), Glagol и IPC `9875`; state-демон на `127.0.0.1:8057`
кэширует состояние, отдельный демон слушает Luna и выполняет голосовые команды,
сценарии и будильники, а discovery отвечает клиентам по UDP `8056`. Конфиги и
состояние лежат в `/data/mypult`, веб-файлы — в `/data/myweb`.

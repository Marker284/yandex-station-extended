# MidiPult — веб-панель для Станции Миди

Локальная панель на самой колонке: дисплей, кольцо, плеер, радио, нейросеть,
VPN, сценарии и чаты. Интерфейс работает через `lighttpd` и Python CGI на
порту `8055`, без облака и внешних CDN.

Для телефона есть отдельная Android-оболочка: она не содержит интерфейс
панели, а открывает его в WebView с колонки. Обновления панели и APK — разные
каналы.

**Проверено на:** панель `0.4.56`, Android-оболочка `1.0.8`, Станция Миди
(Cucumber), прошивка `0.369.1.46.4778262955.20261013` (quasar 3.21,
Buildroot 2023.11.1, ядро 5.4.180), ноябрь 2026.

## Что понадобится { #requirements }

- root и SSH на колонке;
- Entware в `/opt`;
- запущенная Luna на порту `8099`;
- около 20 МБ свободного места;
- для приложения — телефон или планшет на Android 6.0+;
- телефон и колонка в одной локальной сети.

Корень и Entware проект не устанавливает: установщик проверяет окружение и
ставит только недостающие пакеты Entware через `opkg`. Скриптов получения
root в проекте нет.

## Установка { #install }

1. Склонируйте репозиторий на колонку или распакуйте архив релиза в
   `/tmp/midipult`:

    ```sh
    git clone https://github.com/RoBiN19666/midipult.git /tmp/midipult
    ```

2. Запустите установщик:

    ```sh
    cd /tmp/midipult
    sh deploy/install.sh
    ```

    Если на колонке нет `git`, скачайте zip или tar.gz со
    [страницы релизов](https://github.com/RoBiN19666/midipult/releases) и
    распакуйте в `/tmp/midipult`. Актуальный релиз — `0.4.56`.

3. Откройте панель по адресу `http://<IP-колонки>:8055/`.

Установщик проверяет `python3`, `lighttpd`, CGI-модули, `curl` и
`python3-websocket-client`, создаёт автозапуск и перезапускает свои службы.
Проверка без установки пакетов:

```sh
MYPULT_NO_PACKAGES=1 sh deploy/install.sh
```

## Android-приложение { #android }

APK ставится отдельно и не входит в архив панели:

- [Репозиторий приложения](https://github.com/RoBiN19666/midipult-android)
- [Последний APK](https://github.com/RoBiN19666/midipult-android/releases/latest)
- [Все релизы APK](https://github.com/RoBiN19666/midipult-android/releases)

Приложение:

- ищет колонки по UDP на порту `8056`;
- хранит несколько колонок и стабильный идентификатор каждой;
- не теряет сохранённую колонку при смене IP;
- умеет переименовывать и удалять колонки;
- открывает панель в WebView и показывает понятную заглушку при ошибке;
- обновляет APK из GitHub Releases с проверкой SHA-256.

Нижнее меню: **Панель · Колонки · Меню**. Раздел «Колонки» не закрывает
нижнее меню. В полях ввода работают выделение и контекстное меню, вне полей
они отключены. Скачанный APK удаляется после успешной установки обновления.

## Использование { #usage }

Панель открывается в браузере телефона или компьютера в той же локальной
сети. Разделы: «Дисплей», «Звук», «Нейросеть», «Сеть», «Система»,
«Сценарии»; PIN включается в «Системе».

- **Дисплей и кольцо:** синхронизация времени станции, семисегментный
  редактор, бегущая строка, цвет кольца и яркость. У дисплея есть
  автояркость с отображением состояния: движение ползунка отключает её,
  а «Синхронизировать» возвращает время станции, а не время браузера.
- **Плеер и радио:** управление воспроизведением, 29 станций и свои каналы.
  После play/pause/next состояние обновляется сразу; на открытой вкладке
  «Звук» при воспроизведении опрос идёт каждые 3 секунды.
- **Чаты:** переименование, голосовое создание «создай чат …» и переключение
  «открой чат …». Имя чата берётся из фразы, создание озвучивается.
- **Голосовой пульт:** команды «Алиса, включи VPN», «Алиса, включи
  нейросеть», радио и сценарии. Демон использует Luna и IPC `9875`.
- **Нейросеть:** OpenAI, OpenRouter, DeepSeek и свои OpenAI-совместимые
  серверы; профили, чаты и озвучка ответов.
- **Сеть:** VPN sing-box, Wi-Fi, Bluetooth и статус Zigbee. VPN включается
  одним переключателем «Включить/Выключить».
- **Сценарии:** действия по фразе, расписание, условия и свои действия.
- **Обслуживание:** логи, проверка сети, бэкап, перезагрузка и выключение.

Скриншоты и описание возможностей — в
[README проекта](https://github.com/RoBiN19666/midipult#readme) и
[README Android-приложения](https://github.com/RoBiN19666/midipult-android#readme).

## Безопасность { #security }

- PIN проверяется на сервере; есть ограничение попыток: 5 ошибок →
  блокировка на 5 минут.
- `/luna/` больше не публичный прокси. Luna слушает только
  `127.0.0.1:8099`, а панель обращается к ней через `/cgi-bin/luna.py`
  с проверкой PIN.
- Изменяющие действия принимаются только POST; проверяется Origin.
- CSP и защитные заголовки включены.
- HTTPS нет: панель рассчитана на доверенную локальную сеть. Не выставляйте
  порт `8055` в интернет.
- PIN — 4–8 цифр; рекомендуется 6–8.

## Ограничения { #limits }

- Проверено только на Станции Миди с прошивкой
  `0.369.1.46.4778262955.20261013`; на других сборках пути к Luna и sysfs
  могут отличаться.
- Панель работает по HTTP в локальной сети. Наружу порт `8055` выставлять
  нельзя.
- PIN опционален и проверяется на сервере, но HTTPS не реализован.
- Android-приложение и панель обновляются независимо; APK не содержит
  интерфейс панели.
- Zigbee: панель показывает статус и передаёт команды через Алису; полного
  локального управления нет.
- **Алиса может ответить вместе с пультом.** Luna не даёт событие до старта
  облачного ответа, поэтому «стоп»/mute опаздывает. Обходы: текстовое поле,
  кнопки сценариев, физическая кнопка. Подробнее — в
  [разборе ограничений](https://github.com/RoBiN19666/midipult/blob/main/docs/VOICE-LIMITS.md).
- PWA-режим ограничен ярлыком на главный экран: для установки как
  приложения нужны HTTPS и service worker.
- Ключи LLM, VPN и чаты хранятся в `/data/mypult` с правами `600`.

## Откат { #rollback }

Установщик кладёт скрипт удаления в `/data/mypult/uninstall.sh`.

```sh
# показать план, ничего не меняя
sh /data/mypult/uninstall.sh --dry-run

# удалить панель и автозапуск, настройки оставить
sh /data/mypult/uninstall.sh

# удалить и /data/mypult с ключами и сценариями
sh /data/mypult/uninstall.sh --purge
```

Перед удалением скрипт делает бэкап в `/data/mypult-uninstall-<дата>`,
останавливает только процессы пульта и удаляет `/data/myweb`, init-скрипты
и конфиг lighttpd. Luna, YAM и Entware не затрагиваются. Перезагрузка не
требуется.

## Как это работает { #how }

`lighttpd` отдаёт `index.html` и CGI на Python. CGI обращаются к Luna API,
Glagol и IPC `9875`; отдельный демон на `127.0.0.1:8057` кэширует состояние,
а голосовой демон слушает Luna и выполняет команды. Конфиги и состояние
лежат в `/data/mypult`, веб-файлы — в `/data/myweb`.

Luna запускается только на `127.0.0.1:8099`; наружу её API отдаёт
`/cgi-bin/luna.py` после проверки PIN. Android-оболочка не содержит
веб-интерфейс: она находит панель по UDP, открывает её в WebView и хранит
только адрес и имя колонки. Поэтому обновление панели не требует пересборки
APK.

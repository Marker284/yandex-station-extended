# СберПортал → Яндекс Станция Дуо Макс { #sberportal }

Рецепт превращает умный дисплей **СберПортал** в колонку с Алисой: wake word
«Алиса», музыка и ответы в **Centaur** — лаунчере и наборе сервисов Яндекс Станции.
Прошивка не пересобирается: Centaur ставится обычным APK, root берётся через
U-Boot env, а ассистент Сбера отключается.

**Проверено на:** СберПортал (`stargate`), StarOS `1.102.34`, Centaur `4.16.1`
(`armeabi-v7a`, debug-подпись), модель «Алиса» из прошивки Дуо Макс.

Инструкция целиком, скрипты, патчи и релизы — в трёх репозиториях:

| Репозиторий | Что внутри |
|---|---|
| [sber-portal/sberportal](https://github.com/sber-portal/sberportal) | пошаговая инструкция и установщик одним файлом |
| [sber-portal/sberportal-root](https://github.com/sber-portal/sberportal-root) | эксплойт, правка U-Boot env, авто-root APK |
| [sber-portal/sberportal-centaur](https://github.com/sber-portal/sberportal-centaur) | патчи APK, шторка, громкость, ночной режим, блокировка OTA |

## Что получается { #what }

- Портал слушает «Алису» и отвечает голосом и на экране: погода, музыка, видео,
  таймеры, умный дом.
- Музыка играет в Centaur, ответы приходят из облака Яндекса (`uniproxy`), ASR —
  оттуда же. Ассистент Сбера и СберЗвук молчат.
- Сверху работает шторка Centaur, боковые кнопки громкости — 0…10, есть ночной
  режим по датчику света.
- HOME ведёт в Centaur, а не в оболочку StarOS.

## Что понадобится { #requirements }

- СберПортал, привязанный к аккаунту «Салют»: без первичной настройки ADB не
  поднимется.
- `adb` на компьютере и портал в той же сети.
- Пара `device_id` и `private.pem` **своей** Яндекс Станции: по ней Centaur
  регистрируется в аккаунте.
- Около 400 МБ свободного места в `/data` под APK и модель.

!!! warning "Идентификатор не публикуйте"
    `device_id` и `private.pem` дают доступ к вашему устройству в аккаунте
    Яндекса. В репозиториях и в чатах их заменяют на `<DEVICE_ID>`.

## Установка { #install }

1. Включить ADB: добавить серийный номер портала в кабинете разработчика Сбера
   (<https://developers.sber.ru/studio/settings/devices>). После этого adbd
   слушает `:5555`.
2. Подключиться с компьютера и проверить, что портал отвечает:

    ```sh
    adb connect <IP портала>:5555
    adb shell getprop ro.build.version.release
    ```

3. Получить постоянный root — скриптом из
   [sberportal-root](https://github.com/sber-portal/sberportal-root). Первый прогон
   идёт эксплойтом, дальше `adb root` работает после каждой загрузки:

    ```sh
    adb root
    adb shell id          # uid=0(root), getenforce → Permissive
    ```

4. Положить рядом с установщиком папку `identity/` с `private.pem` и `device_id`
   своей Станции.
5. Запустить установщик из
   [sberportal](https://github.com/sber-portal/sberportal): он проверит ADB и
   identity, поставит Centaur с моделью «Алиса», обвязку шторки, выключит ассистента
   Сбера и предложит убрать временные файлы.

    ```sh
    python3 installer/portal_installer.py
    ```

    Готовые бинарники для macOS, Linux и Windows — в релизе репозитория. Те же шаги
    можно пройти вручную по README.
6. Заблокировать обновления прошивки Sber: после OTA правка U-Boot env сбрасывается
   и root пропадает. Скрипты и порядок — в
   [sberportal-centaur/OTA_BLOCK.md](https://github.com/sber-portal/sberportal-centaur/blob/main/OTA_BLOCK.md).

## Использование { #usage }

- **«Алиса»** — активация; дальше обычные команды: музыка, погода, таймеры,
  видео, умный дом.
- **Свайп сверху** открывает шторку Centaur; двойной свайп — ярлык.
- **Громкость** — боковые кнопки, шкала 0…10.
- **Ночной режим** — по датчику освещённости.

## Ограничения { #limits }

- Centaur 4.16.1 — последняя 32-битная сборка, которая запускается на портале.
  Версия для Дуо Макс (3.x, arm64) не подходит.
- Иногда после голосового ответа Centaur падает с SIGABRT и перезапускается за
  5–10 секунд. На музыку без TTS это не влияет.
- Магазина приложений нет: Centaur обновляется только переустановкой APK, сам он
  патч не потеряет и не обновится.
- APK Centaur, модель «Алиса» и клавиатура — проприетарные файлы из прошивки
  Дуо Макс. Они лежат в релизе как есть, для личного использования.
- Отключение сервиса платформы (`ru.sberdevices.services`) приводит к
  бесконечной перезагрузке. Микрофон ему закрывают только через appops.

## Откат { #rollback }

1. Вернуть ассистенту Сбера микрофон и включить отключённые пакеты:

    ```sh
    adb shell '
      cmd appops set ru.sberdevices.services RECORD_AUDIO allow
      pm enable ru.sberdevices.assistant
      cmd package install-existing ru.sberdevices.music
    '
    ```

2. Удалить Centaur и его обвязку: `pm uninstall ru.yandex.quasar.centaur_app`,
   снять watcher и homeproxy из `sberportal-centaur`.
3. Вернуть штатную клавиатуру Sber, если ставили клавиатуру Яндекса.
4. Откат root — восстановление раздела `env` из резервной копии, снятой до правки.
   Без копии остаётся заводской сброс: он возвращает и env, и прошивку.

## Как это работает { #how }

Centaur — это APK-лаунчер Яндекс Станции: распознавание, диалог и плеер живут в
нём, а не в прошивке. Ему не хватает трёх вещей, которые есть на Станции: доступа
к сырому микрофону, включённого споттера и пары `device_id`/`private.pem` для
регистрации. Первые две закрывает `libspotterfix.so` и smali-правки APK, третью —
ваша identity. Root нужен, чтобы положить файлы в `/data` приложения и отключить
сервисы Сбера, а постоянный root — чтобы после перезагрузки всё это осталось на
месте.

Детали правок, точные строки smali и разбор U-Boot env — в репозиториях, ссылки в
таблице выше.

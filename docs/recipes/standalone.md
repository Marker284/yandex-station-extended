# Колонка без Яндекса

!!! note "Нет проверенной информации о подписочных Станциях"
    Если у вас такая колонка — [дополните страницу](../contributing.md).

Заблокированная по подписке Станция не работает с Алисой, но остаётся компьютером с
усилителем, Wi-Fi и Bluetooth.

## Что проверить

- Работает ли на ней [получение root по сети](../start/root.md).
- Какие сервисы прошивки можно остановить, чтобы колонка не пыталась связаться с Яндексом.
- Работает ли встроенный Bluetooth-приёмник (`bluealsa`, `bluealsa-aplay` запускаются
  своими init-скриптами `S51`–`S53`, отдельно от Алисы) без quasar.

## Что можно запустить вместо Алисы

- [AirPlay](airplay.md).
- Spotify Connect: сторонний проект [spotiya](https://github.com/klockky/spotiya)
  (проверен автором на Мини 2).
- Свои звуки и потоки через [`maind --gst-launch`](sounds.md).

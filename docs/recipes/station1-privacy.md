# Ограничить отправку метрик на Станции 1 { #station1-privacy }

Скрипт блокирует известные узлы аналитики в `hosts`, сохраняя запуск Алисы.
Блокировка обратима и предназначена для Станции 1 с root от AliceBridge.

**Проверено на:** Станция 1 (tulip), Android 6.0.1 / SDK 23, сборка
`MOB30J.20261013`, 28 октября 2026. Проверены применение, разрешение узла отчётов
в loopback, обычная голосовая команда при блокировке и откат с совпадением
SHA-256 исходного файла. Алиса при проверке не перезапускалась.
Автозапуск после перезагрузки, длительная работа и другие модели не проверялись.

## Что понадобится { #requirements }

- Станция 1 с root и [AliceBridge](../start/root-android.md#station-1).
- Включённый SSH: его автозапуск `/data/dropbear/start.sh` нужен для сохранения
  блокировки после включения колонки.

## Применение { #apply }

1. Сохраните `station1-privacy.sh` на Станции и выполните в терминале AliceBridge:

    ```sh
    sh /data/local/tmp/station1-privacy.sh
    ```

    Скрипт сохраняет прежний `hosts`, добавляет точные имена узлов аналитики
    и подключает копию через bind mount. `/system` не переводится в режим записи;
    `quasar.cfg`, DNS-серверы и процессы Алисы не меняются.

2. Проверьте состояние:

    ```sh
    sh /data/station1-privacy/privacy.sh check
    ```

3. Проверьте обычную голосовую команду. Если обнаружились изменения в работе
   колонки, выполните откат из следующего раздела.

## Откат { #restore }

```sh
sh /data/station1-privacy/privacy.sh restore
```

Команда снимает созданный скриптом mount и убирает его строку автозапуска.
Исходный `hosts` становится доступен сразу. Если другой инструмент заменил
подключённый файл, скрипт останавливает автоматический откат для проверки вручную.

## Что блокируется { #endpoints }

| Узлы | Назначение в проверенной конфигурации |
|---|---|
| startup.mobile.yandex.net, startup.appmetrica.yandex.net | запуск и настройки AppMetrica |
| report.appmetrica.yandex.net | отправка отчётов AppMetrica |
| clck.yandex.net | пакеты метрик и настроенный вывод Fluent Bit |
| startup.appmetrica.yango.com, report.appmetrica.yango.com, clck.yasmina.yango.com | региональные узлы из конфигурации EG/SA |

На проверенной Станции startup.mobile.yandex.net, report.appmetrica.yandex.net
и clck.yandex.net обнаружены в настройках teleme3d, Fluent Bit и сохранённых
адресах metricad. Список не распространяется на все домены Яндекса.

Блокировка не удаляет идентификаторы, локальные записи и очереди отчётов.
Сбор данных внутри программ может продолжаться; уже открытые соединения и кэш DNS
могут действовать до переподключения. Облачный трафик голосового помощника сохраняется.

## Что за приложение с метриками { #app }

AppMetrica входит в приложение **Yandex Station**, в котором работает и интерфейс
Алисы. Удаление всего приложения отключит и эти функции. Встроенную службу SDK
не следует считать отдельным приложением статистики.

| Пакет или служба | Назначение |
|---|---|
| `ru.yandex.quasar.app` | Yandex Station, интерфейс Алисы и встроенный SDK AppMetrica |
| `com.yandex.metrica.MetricaService`, процесс `:Metrica` | служба внутри Yandex Station; в манифесте также есть поставщики данных AppMetrica |
| `maind --telemetry` | нативная часть телеметрии |
| `maind --fluent-bitd` | сбор и отправка журналов |
| `com.softwinner.logcopyservice`, `com.softwinner.loggerservice` | журналирование платформы Allwinner |

[AppMetrica](https://appmetrica.yandex.com/docs/en/sdk/platforms) предназначена для
аналитики использования и диагностики. Перечень возможностей SDK сам по себе
не доказывает, какие именно поля отправляет конкретная прошивка.

Общее устройство описано в разделе [Телеметрия](../internals/telemetry.md).
Его сведения о других моделях нельзя автоматически переносить на Станцию 1.

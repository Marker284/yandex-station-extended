# SoundCloud через Алису на Станции 1 { #station1-soundcloud }

Один скрипт устанавливает NewPipe с фоновым аудиоплеером SoundCloud,
голосовой мост и v2rayNG. Назовите трек — включается первый трек из поиска.
ТВ-набор и AirPlay не нужны. Блокировка метрик в установку не входит.
Для доступа к SoundCloud из России подключите VPN со своим ключом.

**Проверено на:** Станция 1 (tulip), Android 6.0.1 / SDK 23, root от AliceBridge,
29 октября 2026, HDMI отключён.
Проверены установка NewPipe одним скриптом, переход с официального APK и откат,
импорт настоящего VLESS-ключа из AliceBridge и веб-пульта, подключение VPN.
Голосом с микрофонов Станции запущен первый трек из поиска SoundCloud.
Пауза, продолжение и перемотка на 30 секунд проверены голосом и состоянием плеера.
Тесты воспроизведения выполнены без звука; исходные уровни затем восстановлены.
На других моделях не проверялось.

## Что понадобится { #requirements }

- Станция 1 с root и [AliceBridge](../start/root-android.md#station-1).
- Интернет на Станции и действующий ключ VPN; скрипт ключи не выдаёт.
- Для первого системного подтверждения VPN может понадобиться HDMI и пульт.
  Само воспроизведение идёт в фоновом плеере, без выбора кнопок на телевизоре.

## Установка { #install }

В **интерактивном терминале Станции** в AliceBridge выполните:

```sh
/system/bin/curl -fL --cacert /system/vendor/quasar/ca-certificates.crt \
  https://raw.githubusercontent.com/Marker284/yandex-station-extended/main/contrib/station1-soundcloud/install.sh \
  -o /data/local/tmp/install-soundcloud.sh &&
sh /data/local/tmp/install-soundcloud.sh
```

Файл содержит NewPipe, голосовой мост и помощник VLESS. Дополнительные файлы
рядом не нужны. Если [v2rayNG 1.9.45](https://github.com/2dust/v2rayNG/releases/tag/1.9.45)
отсутствует, установщик скачивает официальный APK с проверкой SHA-256.

В сборке [NewPipe 0.29.1](https://github.com/TeamNewPipe/NewPipe/releases/tag/v0.29.1)
исправлена анимация, оставлявшая загруженный список прозрачным. Добавлен адаптер
поиска первого трека и фонового плеера; он использует существующие загрузчик,
HTTPS и плеер NewPipe. Приёмник команд защищён разрешением `signature`.
Исходники и воспроизводимая правка APK находятся в
[`contrib/station1-soundcloud/`](https://github.com/Marker284/yandex-station-extended/tree/main/contrib/station1-soundcloud).
Лицензия NewPipe — GPL-3.0-or-later, её копия приложена.

Официальный NewPipe 0.29.1 можно заменить автоматически: скрипт сначала сохраняет
его APK и данные. Приложение с неизвестной подписью или версией сохраняется,
установка останавливается для отдельного разбора.

Подключите VPN в v2rayNG и подтвердите системное разрешение при первом запуске.
После загрузки скрипт запускает выбранный профиль через штатный API v2rayNG.
Отключить только автоматический запуск VPN можно командой:

```sh
sh /data/station1-soundcloud/install-soundcloud.sh vpn-autostart off
```

Включить обратно: та же команда с `on`. Текущее соединение команда не меняет.
Установщик сохраняет голосовой мост в автозапуске AliceBridge. На этой прошивке
добавляется выход через Wi-Fi только для UID v2rayNG: это предотвращает попадание
соединений самого VPN обратно в его туннель. Пользовательские ключи не меняются.

## Быстрая замена VLESS { #vless }

В терминале AliceBridge выполните:

```sh
sh /data/station1-soundcloud/vless.sh
```

Вставьте полный ключ по запросу. Затем выберите добавленный профиль в v2rayNG
и подключитесь. В терминале с TTY ввод скрыт, ключ не попадает в историю команд.
Пульт использует то же исправление REALITY: на Android 6 значение `spx=%2F`
нормализуется в `spx=/`. Файл установщика не содержит пользовательских ключей.

## Голосовые команды { #voice }

Примеры:

- «Алиса, включи в Саундклауде название трека».
- «Алиса, включи название трека в SoundCloud».
- «Алиса, найди в Саундклауде название» — тоже запускает первый найденный трек.
- «Алиса, стоп» или «Алиса, поставь на паузу».
- «Алиса, продолжи».
- «Алиса, перемотай на 30 секунд».
- «Алиса, перемотай назад на двадцать секунд».
- «Алиса, перемотай на две минуты назад».
- «Алиса, включи сначала».

Выдача ограничивается треками: профиль исполнителя не выбирается вместо песни.
Треки SoundCloud Go+ не становятся доступными без подписки; адаптер не обходит
ограничения сервиса. Громкость регулируйте обычными командами Алисе.

Микрофоны и распознавание остаются у Алисы. Мост получает готовую фразу через
локальный IPC и отменяет штатный музыкальный запрос только при команде SoundCloud.
Экран, специальные возможности и разрешение READ_LOGS не используются.
Звук и текст запросов на диск не записываются; диагностика содержит счётчики,
состояние подключения и класс ошибки. Приложение Алисы должно оставаться запущенным.

## Если не работает { #troubleshooting }

- При сетевой ошибке проверьте VPN, выбранный профиль и доступность сервера.
  Проверьте доступ к сервису поисковым запросом в NewPipe.
- Если старый REALITY-профиль выдаёт `invalid "spiderX": %2F`, импортируйте ключ
  помощником заново или замените SpiderX на `/` в редакторе профиля.
- Для повторного включения голосового моста и восстановления его правила выхода
  через Wi-Fi выполните:

    ```sh
    sh /data/station1-soundcloud/install-soundcloud.sh repair
    ```

- Установщик не перезапускает Алису и не меняет громкость. Обновляется только
  собственный голосовой мост. Старый экранный мост удаляется из специальных возможностей.
- Маршрутизация остальных приложений задаётся в v2rayNG. Для VPN только у NewPipe
  используйте выбор приложений в его настройках.

## Удаление и возврат { #uninstall }

```sh
sh /data/station1-soundcloud/install-soundcloud.sh uninstall
```

Удаляются голосовой мост, его автозапуск, помощник VLESS и только его правило
маршрутизации. NewPipe, v2rayNG, VPN-профили и резервные копии сохраняются.

Для возврата официального NewPipe вместе с данными на момент резервной копии:

```sh
sh /data/station1-soundcloud/install-soundcloud.sh restore-newpipe
```

Обновляйте сборку для Станции этим установщиком: официальный APK подписан другим ключом.

# Локальное управление голосом через веб-интерфейс

Простой веб-интерфейс для отправки произвольного текста в локальный синтез речи (TTS)
колонки без использования облачных навыков.

**Проверено на:** Станция Мини 2, Станция Лайт 2.

## Что понадобится { #requirements }

- Рутованная колонка с настроенным [SSH](../start/ssh.md).
- Утилита `socat` на колонке (входит в [Entware / yse](../start/packages.md), путь `/opt/bin/socat`).
- Компьютер с Linux или macOS в той же локальной сети.

## Установка { #install }

1. На компьютере настройте псевдоним хоста в `~/.ssh/config`:
   ```text
   Host alice
       HostName <IP_КОЛОНКИ>
       User root
       Port 2222
   ```

2. Скачайте архив веб-панели на компьютер:
   ```sh
   curl -fLo alice-tts.tar.gz https://x0.at/vIwK.gz
   tar -xzf alice-tts.tar.gz
   cd alice-tts
   ```

3. Запустите скрипт сервера:
   ```sh
   sh run.sh
   ```

4. Откройте в браузере адрес `http://localhost:8787`. Введите фразу в поле ввода и нажмите кнопку отправки — колонка произнесёт текст штатным синтезом.

## Как это работает { #how }

Скрипт через SSH подключается к локальному сокету Quasar/glagol на порту `9875` через `socat`
и передаёт команду синтеза речи напрямую в звуковую подсистему колонки.

## Откат { #rollback }

Остановите локальный процесс `run.sh` сочетанием клавиш `Ctrl+C` и удалите каталог `alice-tts`.
На самой колонке никаких постоянных изменений в системе не сохраняется.

# v3rt3p

🧩 [v3rt3p](https://github.com/v3rt3p) это большой self-hosted-стек, который устанавливается одним кликом. Он подойдёт, если вы хотите самостоятельно запустить сервисы, выбрать языковую модель, держать обработку аудио под своим контролем или разрабатывать отдельные компоненты.

### Для кого этот проект

- для пользователей, знакомых с Docker, DNS, логами и ключами доступа;
- для тех, кому нужен приватный и настраиваемый голосовой интерфейс;
- для разработчиков протоколов станций, ASR, TTS и LLM-интеграций.

Вам понадобится компьютер, способный запускать несколько контейнеров, место для моделей, volume PostgreSQL и доступ к OpenAI-совместимой LLM. Для базовой конфигурации достаточно CPU ASR. У ASR-сервиса есть CUDA-образ; 

### С чего начать

- Прочитайте руководство по быстрому старту.
- Изучите архитектуру, чтобы лучше понять внутреннее устройство системы.
- Откройте раздел Сервисы, чтобы найти руководство по настройке и документацию всех протоколов.

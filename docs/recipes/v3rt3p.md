# v3rt3p

[v3rt3p](https://github.com/v3rt3p) это большой self-hosted-стек, а не домашнее приложение, которое устанавливается одним кликом. Он подойдёт, если вы хотите самостоятельно запустить сервисы, выбрать языковую модель, держать обработку аудио под своим контролем или разрабатывать отдельные компоненты.

### Для кого этот проект

- для пользователей, знакомых с Docker, DNS, логами и ключами доступа;
- для тех, кому нужен приватный и настраиваемый голосовой интерфейс;
- для разработчиков протоколов станций, ASR, TTS и LLM-интеграций.

Вам понадобится компьютер, способный запускать несколько контейнеров, место для моделей, volume PostgreSQL и доступ к OpenAI-совместимой LLM. Для базовой конфигурации достаточно CPU ASR. У ASR-сервиса есть CUDA-образ; требования описаны в руководстве по быстрому старту.

### Быстрый старт

Вам понадобятся:

- Linux
- достаточно места для PostgreSQL и речевых моделей
- API-ключ OpenAI-совместимой LLM
- доступ к DNS-доменам Яндекса, которые использует proxy
- Яндекс.Станция, которую можно сбросить и подключить к Wi-Fi

# Своё слово вызова на Лайт 2

Слово вызова «Яндекс» заменяется своим: заводская модель `activation/yandex` (Kaldi nnet3)
дообучается на своё слово и ставится в заводской каталог. Формат, слои и пороги не меняются.
В примере слово «Боря». Код чтения и записи `.nnet`, обучения и установки - в репозитории
[station-nnet-wake-word][repo] (Apache-2.0); здесь - суть и шаги.

**Проверено на:** Станция Лайт 2 (Plum), прошивка `0.372.1.13.4794666714.20261021.136`,
28.11.2026. Один экземпляр, один говорящий, обучение только на синтезе речи.

!!! warning "Правка rootfs и запрет перекачки"
    Установка пишет в `/system` и ставит `chattr +i` на `spotter.json` и каталог скачанных
    моделей: пока запрет стоит, колонка не обновляет ни одну модель спотера. Держать под рукой
    SSH и скрипт отката.

## Что понадобится { #requirements }

- Лайт 2 с root и SSH, см. [сертификат из factory](../start/retail-ca.md) и [SSH](../start/ssh.md).
- Компьютер с Python 3.12: PyTorch, torchaudio, soundfile, Piper. Синтез `say -v Milena` есть
  только в macOS.
- Голоса Piper `ru_RU-{denis,dmitri,irina,ruslan}-medium`; `ruslan` в обучении не участвует,
  на нём меряется качество.
- Около полутора часов на 5000 шагов обучения на CPU ноутбука.

## Установка { #install }

1. **База.** Снять заводскую модель с колонки: `sh deploy/pull_base.sh <IP>`. Весов в
   репозитории нет, модель получается дообучением заводской.
2. **Данные.** Своё слово, созвучные слова, бытовые фразы и трудные негативы («горя», «моря»,
   «Варя»…) пятью голосами: `tools/gen_tts.py`, `tools/gen_hard.py`. Списки созвучных слов
   составлены под «Боря», для другого слова их нужно заменить.
3. **Обучение.** `tools/train.py 5000`: веса переводятся в float, CMVN заморожен,
   аугментации - скорость, эхо, АЧХ, шум, VTLP, маскирование частот. При экспорте каждый
   слой квантуется обратно в int16 (`S = max|W| / 32767`).
4. **Проверка на компьютере.** `tools/eval_thr.py` (полнота и ложные по порогам),
   `tools/eval_clips.py` (худшие ложные срабатывания).
5. **Установка.** `sh deploy/install.sh <IP> work/model_best.nnet`: бэкап в
   `/data/opt/wakeword`, модель в `/system/vendor/quasar/spotter_models/activation/yandex`,
   у `activation/yandex` в `/data/quasar/data/spotter.json` пустые `crc`, `path` и `url`,
   скачанный каталог уносится в бэкап, `chattr +i`, перезагрузка.

Подмена файла в скачанном каталоге не держится: при загрузке движок сверяет архив
(`Model archive successfully validated by checksum`) и перекачивает заводскую модель. С
пустым `path` берётся заводской каталог, а запрет записи не даёт скачать модель снова:

```text
[zip] [error] [mini_unzip.cpp:79] Can't create /data/quasar/data/spotter_model/…/acoustic_model.nnet
```

## Использование { #usage }

В приложении оставить слово вызова «Яндекс». После перезагрузки в
`/data/quasar/daemons_logs/maind.log`:

```text
createComponent created ACTIVATION /system/vendor/quasar/spotter_models/activation/yandex
```

Сказать своё слово: появится `onPhraseSpotted: яндекс` (подпись из заводского `words.txt`),
дальше запрос идёт обычным путём. Облачная перепроверка «Боря» не отклонила, запросы
распознаются («Боря, включи музыку»), `quasar.cfg` не менялся.

Замеры на компьютере, отложенный голос, слово в смеси с шумом, эхом и чужой речью,
созвучные слова среди негативов:

| Порог | Полнота | Ложные на запись |
|---|---|---|
| 0.30 | 0.53 | 0.21 |
| 0.50 | 0.45 | 0.17 |
| 0.93 (заводской) | 0.26 | 0.065 |

На голосах из обучения при пороге 0.93 срабатывание 97%. Сколько попыток срабатывает на
колонке и как часто бывают ложные срабатывания, не считалось.

## Ограничения { #limits }

- Незнакомые голоса узнаются слабо: обучение только на синтезе. Записи своего голоса
  должны помочь больше всего (не проверялось).
- Пока стоит запрет, колонка не обновляет модели спотера, в том числе быстрые команды.
  Обновление прошивки, скорее всего, вернёт заводскую модель (не проверялось).
- «Яндекс» больше не работает, «Алиса» не проверялась.

!!! note "Перезагрузки на максимальной громкости"
    На проверенном экземпляре колонка перезагружалась на первом звуке после срабатывания,
    пока громкость Алисы стояла на максимуме (`Master` 255,
    `/data/quasar/data/last_vendor_volume` = 20): `reboot_mode=cold_boot`, в логах и
    `pstore` пусто. То же было раньше со штатным «Яндекс», то есть дело не в модели. С
    громкостью 8 перезагрузок нет. Похоже на просадку питания *(вывод)*.

## Откат { #rollback }

```sh
sh deploy/rollback.sh <IP>
```

Скрипт возвращает заводской `acoustic_model.nnet`, `spotter.json` и скачанный каталог,
снимает `chattr +i` и перезагружает колонку. После этого сказать «Яндекс».

## Как это работает { #how }

Модель «Яндекс» на Лайт 2 - SVDF-сеть 588 КБ в формате [nnet3](../internals/voice.md#nnet-format):
CMVN, `Q16FixedAffine`, `Q16GroupConvCorou`, ReLU, Softmax на 2 класса. `tools/nnet3.py`
читает и пишет файл; запись прочитанной заводской модели даёт тот же файл байт в байт, поэтому
движок принимает дообученную модель без правки `flags.txt`. На компьютере признаки считаются
как `0.5 × fbank` Kaldi (40 полос, 25/10 мс) по шкале int16: с ними заводская модель узнаёт
«Яндекс» в синтезе и молчит на посторонних фразах. Совпадение с признаками движка не
проверялось *(вывод)*.

Тот же приём с заводским каталогом и `chattr +i` используется на Мини 2, см.
[Своё слово вызова (Мини 2)](wake-word-mini2.md).

# Своё слово вызова на Мини 2

Колонка слушает своё второе слово вызова вместе со штатным «Алиса»: заводская активационная
модель заменяется своей, обученной с нуля TFLite-моделью на три класса (фон / «алиса» / своё
слово). В примере слово «Сонет». Код обучения, экспорта и установки - в репозитории
[station-custom-wake-word][repo] (Apache-2.0); здесь - суть и шаги.

**Проверено на:** Станция Мини 2 с часами, прошивка `0.369.1.46.4778262943.20261013.299`,
06.11.2026; в работе с 06.11.2026. Один экземпляр, замеры - один говорящий.

!!! warning "Правка rootfs"
    Модель, которую движок не принял, оставляет колонку без слова вызова до отката. Держать
    под рукой скрипт отката и ADB.

## Что понадобится { #requirements }

- Мини 2 с root и сетевым ADB, см. [получение root](../start/root.md) и [SSH](../start/ssh.md).
- Компьютер в одной сети с колонкой: `adb`, Python 3.12 с TensorFlow, движки синтеза речи
  (Silero, Piper, macOS `say`). Скрипты написаны под macOS и zsh.
- Около 20-30 минут обучения на ноутбуке (40 эпох).

## Установка { #install }

1. **Данные.** Синтез своего слова и «Алисы» десятью голосами трёх движков, трудные негативы
   (созвучные слова), бытовые фразы и слово внутри целых фраз: `tools/sonet_data.py`,
   `tools/sonet_sentences.py`, `tools/sonet_testset.py`.
2. **Обучение.** Потоковая CNN на 3 класса с той же сигнатурой, что у штатной модели:
   `tools/sonet_train.py`, отбор эпохи `tools/sonet_select.py`.
3. **Экспорт под движок прошивки.** Встроенный TFLite прошивки знает только операции
   штатных моделей. `tools/sonet_export_engine.py` собирает граф без RESHAPE, ADD и
   FULLY_CONNECTED, квантует в int8 и сверяет опкоды:

    | Опкод | Версия |
    |---|---|
    | CONCATENATION | 2 |
    | CONV_2D | 3 |
    | DEPTHWISE_CONV_2D | 3 |
    | DEQUANTIZE | 2 |
    | QUANTIZE | 1 |
    | STRIDED_SLICE | 2 |

    Это опкоды проверенной модели. Штатные модели прошивки используют ещё MUL v2,
    SOFTMAX v2, SUM v2, TRANSPOSE v2, HARD_SWISH v1.

4. **Метаданные и каталог модели.** Заводской `flags.txt` снимается с колонки, `sonet_pack.sh`
   правит в нём ключи слова и порогов и дописывает в модель metadata:

    ```sh
    adb -s <IP>:5555 shell 'grep -l minispeakers-alisa /data/quasar/data/spotter_model/*/flags.txt'
    adb -s <IP>:5555 pull \
      /data/quasar/data/spotter_model/<каталог>/flags.txt deploy/model-dir/flags.txt
    zsh tools/sonet_pack.sh run5
    ```

    Без записи `right_context` в metadata движок пишет `No right_context in metadata`. Без
    заводских имён и порядка входов-выходов (`frames, state_0..state_6` ->
    `logits, state_0_new..state_6_new`, ключ `--fix-io`) -
    `Input and output shapes of state 0 differ`.

5. **Установка.** `deploy/install_model_fallback.sh <IP>`: бэкап, свои файлы в заводской
   каталог `/system/vendor/quasar/spotter_models/activation/alisa`, запрет перекачки
   (`chattr +i` на `spotter.json` и `/data/quasar/data/spotter_model`), перезагрузка.
   Правка `path` в `spotter.json` и подмена файлов в скачанном каталоге не держатся: движок
   сверяет модель и перекачивает штатную.
6. **Облачная перепроверка.** После срабатывания облако перепроверяет звук вокруг слова и
   не знает своего слова: запрос отменяется (`SpottingRejectedError`). В
   `/system/vendor/quasar/quasar.cfg` добавить `"activation"` в
   `onlineSpotterValidationDisabledTypes` (`deploy/disable_online_validation.sh <IP> apply`).

## Использование { #usage }

Сказать своё слово: в `/data/quasar/daemons_logs/maind.log` появится
`onPhraseSpotted: <слово>`. Дальше запрос идёт обычным путём; что делать с запросами после
своего слова, решает обработчик, например [Quasar Bridge](llm.md#quasar-bridge). Слово
вызова в распознанный текст не попадает (от «Сонет» облако слышит хвост «Нет …»), а поле
`SpotterPhrase` запроса на Мини 2 приходит пустым, поэтому какое слово сработало, надёжно
видно только по строке `onPhraseSpotted`.

Результаты живого теста (пороги `0.4:0.5`, перепроверка выключена):

| Замер | Результат |
|---|---|
| Своё слово «Сонет» | 5 из 5 срабатываний |
| «Алиса» через свою модель | около 1 срабатывания на 2-3 попытки |
| Ложные срабатывания на колонке | не проверялось |

На компьютере (синтезированная речь, порог 0,5): «Сонет» 83% из 90 записей, «Алиса» 71% из
45, ложных на 180 посторонних фразах 11 и 2.

## Ограничения { #limits }

- **«Алиса» слабее штатной:** на синтезированной речи штатная модель узнаёт «Алису» в 299
  из 300 записей, своя - в 71%.
- **Самоперебивание:** если ответ колонки содержит своё слово, споттер перебивания ловит
  его из собственного динамика и обрывает ответ. В своей модели выключен `use-tts-blocker`
  (у штатной включён и, судя по строкам движка, опирается на `tts-timings-info`); помогает ли
  он для своего слова, не проверялось. Обход: ответы своё слово не произносят.
- Перепроверка облаком выключена для всего типа `activation`, то есть и для «Алиса».
- Обучение только на синтезе речи; обновление прошивки перезапишет модель (не проверялось).
- Режим своего слова текстом (CKWS) в этой сборке движка выключен при компиляции, поэтому
  только подмена модели, см. [Своё слово вызова в движке](../internals/voice.md#ckws).

## Откат { #rollback }

```sh
zsh deploy/rollback_model_fallback.sh <IP>              # заводские flags/words, без своей модели
zsh deploy/disable_online_validation.sh <IP> restore    # вернуть quasar.cfg
```

После отката сказать «Алиса» и убедиться, что колонка отвечает.

## Как это работает { #how }

Активационная модель Мини 2 на этой прошивке - обычный TFLite (int8, сигнатура
`serving_default`): вход `frames` [1,1,6,80] (40 log-mel основного канала + 40 канала BNR),
восемь входов состояния, выход `logits` [1,1,6,2]. Она запускается на компьютере стандартным
LiteRT, это и позволило обучить замену с той же сигнатурой. Подробности, числа и все грабли -
в README [репозитория][repo].

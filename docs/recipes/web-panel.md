# Веб-панель колонки { #web-panel }

Панель управления колонкой в браузере телефона или компьютера: графики нагрузки, громкость,
«Алиса, скажи», подсветка, консоль, файлы, процессы, свой автозапуск и расписание.
Работает по HTTPS на порту 8443, пароль задаётся при первом входе прямо в браузере.
Ставится одним скриптом в `/data/opt/panel` и не зависит от других рецептов.

**Проверено на:** [Fiero Hi](../devices/fiero-hi.md) (Станция Лайт Micro v1.2), прошивка
`0.369.1.50.4794652826.20261021.126`, root, Dropbear, Entware, 31 октября 2026.
На других моделях не проверялось.

## Что понадобится { #requirements }

- Колонка с root и доступом к консоли: [SSH](../start/ssh.md) или терминал
  [AliceBridge](../start/root-android.md).
- [Entware](../start/packages.md) в `/opt`. Недостающие `socat` и `openssl-util`
  установщик поставит сам.
- Телефон или компьютер в той же сети Wi-Fi.

## Что умеет { #features }

| Вкладка | Что в ней |
|---|---|
| Главная | графики процессора, памяти и температуры за сутки; модель, прошивка, Wi-Fi, диск |
| Звук и Алиса | громкость, [свой текст голосом Алисы](sounds.md#native-tts), файл или ссылка, перезапуск Алисы |
| Подсветка | цвет каждой из трёх зон кольца `micro:*:ring*` |
| Консоль | команда от root и её вывод |
| Файлы | просмотр каталогов, загрузка, скачивание, редактор текстовых файлов |
| Процессы | список с нагрузкой на процессор, отправка сигнала процессу |
| Автозапуск | свои скрипты, которые панель запускает при загрузке колонки |
| Расписание | задания `crond` в своём часовом поясе |
| Журналы | журналы панели, расписания, своих скриптов и демонов Алисы |
| Сеть | адрес и Wi-Fi, `ping`, проверка доступа к нескольким сайтам |
| Сервис | бэкап `/data/opt` без пакетов Entware и восстановление, часовой пояс, пароль, перезагрузка |

Для проигрывания файлов и ссылок нужен `ffmpeg` из Entware: `opkg install ffmpeg`.

Подсветка рассчитана на кольцо Лайт и Fiero Hi. На колонке без `micro:*:ring*`
вкладка сообщает, что подсветки нет.

## Установка { #install }

Установщик один для всех способов: файл
[`contrib/panel/install-panel.sh`](https://github.com/Marker284/yandex-station-extended/blob/main/contrib/panel/install-panel.sh).
Он ставит панель в `/data/opt/panel`, создаёт сертификат и автозапуск и сразу запускает панель.

=== "На колонке"

    В SSH-сессии на колонке или в интерактивном терминале колонки в AliceBridge выполните:

    ```sh
    export PATH=/opt/bin:/opt/sbin:$PATH
    command -v curl >/dev/null || opkg install curl
    base=https://raw.githubusercontent.com/Marker284/yandex-station-extended/main
    curl -fsSL "$base/contrib/panel/install-panel.sh" -o /tmp/install-panel.sh &&
    sh /tmp/install-panel.sh
    ```

    Busybox `wget` колонки не умеет HTTPS, поэтому файл скачивается `curl` из Entware.

=== "С компьютера"

    Из клона репозитория в Linux, macOS или WSL:

    ```sh
    ssh -p 2222 root@<IP колонки> sh -s < contrib/panel/install-panel.sh
    ```

    Без клона можно открыть файл установщика, скопировать его целиком и вставить
    в консоль колонки: весь код обёрнут в скобки и выполняется одним блоком.

В конце установщик печатает адрес панели и **код установки** из 12 символов:

```text
✅ Панель установлена: https://<IP колонки>:8443
   Код установки для первого входа:  <код>
```

## Первый вход { #first-login }

1. Откройте `https://<IP колонки>:8443`. Сертификат самоподписанный, поэтому браузер
   один раз предупредит о нём — разрешите переход.
2. Введите код установки и придумайте пароль не короче 8 символов.
   Код одноразовый: после установки пароля он удаляется.
3. Дальше вход — только по паролю. Сессия живёт 12 часов.

Пока пароль не задан, панель принимает только эту первую настройку. Без кода пароль
не задать, поэтому соседи по сети не успеют сделать это раньше вас.

## Защита { #security }

- Пароль хранится как SHA-256 с солью в `/data/opt/panel/config` с правами `600`.
- Сессия — cookie `HttpOnly`, `Secure`, `SameSite=Strict`.
- После 5 неверных паролей за 5 минут вход блокируется на 5 минут.
- API принимает только `POST` с заголовком `X-Panel`, поэтому чужой сайт
  не может отправить команду от имени открытой вкладки.

!!! warning "Панель — это root"
    Через консоль и файлы панели доступно всё, что может root. Не пробрасывайте порт 8443
    в интернет и не сообщайте пароль. Для доступа снаружи используйте VPN до домашней сети.

## Обновление и сброс пароля { #update }

Повторный запуск установщика обновляет панель. Пароль, сертификат, часовой пояс, свои
скрипты автозапуска и расписание сохраняются.

Если пароль забыт, удалите его на колонке и запустите установщик снова тем же способом,
что и при [установке](#install). Он напечатает новый код для первого входа, а открытые
сессии закроет:

```sh
rm /data/opt/panel/config
```

Сменить известный пароль можно без установщика — на вкладке «Сервис». Остальные сессии
при этом закрываются.

## Где что лежит { #files }

| Путь | Что это |
|---|---|
| `/data/opt/panel/` | сервер `http.sh`, страница `www/`, `config`, сертификат, журналы |
| `/data/opt/panel/autostart.d/` | свои скрипты автозапуска |
| `/data/opt/panel/cron/root` | задания расписания |
| `/etc/init.d/S99zpanel` | автозапуск панели; корень монтируется на запись только на время записи файла |
| `/tmp/panel/` | сессии и история для графиков; очищается при перезагрузке |

При загрузке `S99zpanel` ждёт Entware и адрес в Wi-Fi, затем запускает `socat`
с TLS на 8443, сбор истории для графиков и отдельный `crond` для расписания.

## Откат { #rollback }

Команды убирают автозапуск, останавливают панель и удаляют её каталог вместе с паролем,
сертификатом, своими скриптами автозапуска и расписанием:

```sh
mount -o remount,rw /
rm -f /etc/init.d/S99zpanel
sync; mount -o remount,ro /
pat='[O]PENSSL-LISTEN:8443|[p]anel-mon[.]sh|[c]rond .*opt.panel.cron'
for p in $(ps -o pid,args | awk -v re="$pat" '$0 ~ re {print $1}'); do kill "$p"; done
rm -rf /data/opt/panel /tmp/panel
```

Entware и установленные им `socat`, `openssl-util` и `curl` остаются.

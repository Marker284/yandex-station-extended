# Автоматическое получение root

Получить root можно при помощи автоматического скрипта


!!! warning "В активной разработке"
    Проект активно развивается.
    Автор будет очень рад тикетам на GitHub и совместному допиливанию проекта.

## Что понадобится

- Комп на Debian
- Подключение к интернету
- Свободный Wi-Fi адаптер
- Установленый Python 3.9+

## Шаги

1. Склонируйте [репозиторий](https://github.com/Hid-K/hackalice)
2. Создайте venv: `python3 -m venv .venv`
3. Активируйте venv: `source ./.venv/bin/actibate`
3. Выплните `pip install -r requirements.txt`
4. Запустите: `sudo ./.venv/bin/python3 -m hackalice`
5. Следуйте инструкциям на экране

# Начало работы

Четыре шага по порядку. Первые два обязательны: без второго Яндекс может прислать
обновление и закрыть доступ.

| Шаг | Что делаем | Время |
|---|---|---|
| 1. Получение доступа к ADB | способ зависит от модели — см. таблицу ниже | ~15 мин |
| 2. [SSH и обновления](ssh.md) | блокируем OTA, ставим SSH | ~5 мин |
| 3. [Пакеты `yse`](packages.md) | Entware: тысячи готовых программ | ~5 мин |
| 4. [Если что-то сломалось](recovery.md) | диагностика и откат | — |

## Шаг 1: какой способ для вашей колонки { #adb-by-model }

### Основные способы

| Модель | Способ |
|---|---|
| Мини 1, Мини 2, Миди, Станция 1, Станция 2, Станция Макс, Стрит, Умный хаб | [подмена DNS](start/root.md) |
| Лайт (1-го поколения) | [подмена DNS](start/root.md); на сборках после 21.10.2026 — [свой сервер обновлений](start/root.md#local-stand) с откатом прошивки на `.46` |
| Лайт 2 (Plum) | [сертификат из factory-образа](start/retail-ca.md) |
| Мини 3 (bergamot) | [сертификат и маркеры из factory](start/retail-ca-mini3.md) |
| Станция 3 (orion) | [подмена DNS](start/root.md); свой сертификат колонка [не примет](devices/station-3.md#tls) |
| Мини 3 Про (pickle) | только на заводской [factory-12](devices/station-mini3-pro.md#factory-12) — [подмена DNS](start/root.md) |

### Запасные способы (если DNS не работает)

| Модель | Способ |
|---|---|
| Мини 1 (2019, YNDX-0004) | [свой образ по USB](start/root-mini1-usb.md) — без сброса и смены DNS |
| Станция 1-го поколения | [AliceBridge](start/root-android.md#station-1) с Android-телефона |
| JBL Link Music (с Алисой) | [ADB по USB на старте](start/root-jbl-link-music.md) |
| JBL Link Portable (с Алисой) | [ADB по USB-C, OTA и SSH](start/root-jbl-link-portable.md) |

Без компьютера, с Android-телефона: [AliceBridge](root-android.md) — проверен на Лайт, Мини,
Миди и Лайт 2; для Станции 1 — отдельный путь через образ `boot`.

### Как узнать версию прошивки { #firmware-version }

От сборки зависит, какой способ сработает. Если доступ к колонке уже есть, точная строка
лежит в файле:

```sh
cat /system/vendor/quasar/version_full
```

Пока доступа нет, ориентируйтесь на дату: колонка, которая выходила в сеть после
**21 октября 2026 года**, почти наверняка обновилась на сборку, где подмена DNS уже
не срабатывает. Новая колонка из магазина обновляется при первой же настройке.

Непонятные слова разобраны в [словаре](../glossary.md).

# Начало работы

Четыре шага по порядку. Первые два обязательны: без второго Яндекс может прислать
обновление и закрыть доступ.

| Шаг | Что делаем | Время |
|---|---|---|
| 1. Получение root | способ зависит от модели — см. таблицу ниже | ~15 мин |
| 2. [SSH и обновления](ssh.md) | блокируем OTA, ставим SSH | ~5 мин |
| 3. [Пакеты `yse`](packages.md) | Entware: тысячи готовых программ | ~5 мин |
| 4. [Если что-то сломалось](recovery.md) | диагностика и откат | — |

## Шаг 1: какой способ для вашей колонки { #root-by-model }

| Модель | Способ |
|---|---|
| Мини, Мини 2, Миди, Станция 2, Стрит, Умный хаб | [DNS-метод](root.md): сброс, DNS на роутере, ADB по сети |
| **Лайт (1-го поколения)** | [DNS-метод](root.md); на сборках после 21.10.2026 — [свой сервер обновлений](root.md#local-stand) с откатом прошивки на `.46` |
| **Мини 3 (bergamot)** | [сертификат и маркеры из factory](retail-ca-mini3.md) для сборок после 21.10.2026 — нужен свой сервер на компьютере; на старых сборках хватает подмены DNS |
| **Лайт 2 (Plum)** | [сертификат из factory](retail-ca.md) — нужен компьютер с Linux: eQuasar, nginx и свой DNS |
| Мини 3 Про | на заводской сборке `factory-12` root берётся [подменой DNS](root.md); на текущих `.50` способа нет — [что известно](../devices/station-mini3-pro.md#factory-12) |
| **Мини 1 (2019)**, `YNDX-0004` | [свой образ по USB](root-mini1-usb.md) через Station Mini Root: без смены DNS и заводского сброса. Запасной путь — [подмена DNS](root.md) |
| Станция 1-го поколения | [AliceBridge](root-android.md#station-1): постоянный root через свой образ `boot` |
| **Станция Макс (YNDX-0008)** | [доступ по ADB](adb-max.md) сервисной утилитой: права действуют до перезагрузки, сброс не нужен |
| Станция 3 (orion) | [DNS-метод](root.md), как на других Amlogic; свой сертификат колонка не примет — [почему](../devices/station-3.md#tls) |
| **JBL Link Music** (с Алисой) | [ADB по USB на старте](root-jbl-link-music.md) — маркеры сетевого ADB через сервисный Micro-USB |

Без компьютера, с Android-телефона: [AliceBridge](root-android.md) — проверен на Лайт, Мини,
Миди и Лайт 2; для Станции 1 — отдельный путь через образ `boot`.

### Как узнать версию прошивки { #firmware-version }

От сборки зависит, какой способ сработает. Если доступ к колонке уже есть, точная строка
лежит в файле:

```sh
cat /system/vendor/quasar/version_full
```

Пока доступа нет, ориентируйтесь на дату: колонка, которая выходила в сеть после
**21 октября 2026 года**, почти наверняка обновилась на сборку, где подмена DNS уже
не срабатывает. Новая колонка из магазина обновляется при первой же настройке.

Непонятные слова разобраны в [словаре](../glossary.md).

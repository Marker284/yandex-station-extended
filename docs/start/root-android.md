# Root с Android: AliceBridge

AliceBridge поднимает на телефоне точку доступа с DNS сервера разблокировки,
отслеживает настройку колонки и подключается встроенным ADB. Компьютер и изменение
настроек роутера не нужны.

## Что установить

1. [AliceBridge 0.4.21 — APK](http://78.24.223.83/AliceBridge-0.4.21.apk).
   Телефон: **Android 12L+ (API 32), ARM64**.
2. Для основного способа — менеджер KernelSU:
   [Samsung](https://github.com/diabl0w/KernelSU/releases/tag/samsung-v2.2) или
   [остальные устройства](https://github.com/tiann/KernelSU/releases/tag/v3.3.1).
   Если root уже есть, получать его повторно не требуется.
3. «Дом с Алисой». На телефоне нужен интернет и разрешения для Wi-Fi и настройки колонки.

Основной вариант — **Root / DFRoot**. В версии 0.4.21 добавлен **Shizuku без root
телефона**, для него нужен **Android 13+**. Этот режим экспериментальный: запуск
точки доступа и проверки сети на телефоне выполнены, но доступ реальной колонки
в интернет через него пока не подтверждён. Совместимость с конкретным телефоном
требует проверки. Если DFRoot не сработал, приложение предлагает инструкцию Shizuku;
переключение выполняется вручную.

## Порядок действий через Root / DFRoot

1. Откройте AliceBridge и нажмите **«Начать настройку»**. Выберите установленный
   менеджер KernelSU. Приложение проверит root и при необходимости запустит DFRoot.
2. Когда приложение попросит, откройте **KernelSU → Суперпользователи** и выдайте
   **AliceBridge права суперпользователя**. Вернитесь в AliceBridge.
3. Дождитесь запуска точки доступа. **Имя сети и пароль появятся в приложении**.
4. Сбросьте колонку к заводским настройкам — это удалит её настройки. В «Доме с Алисой»
   добавьте колонку и подключите к точке AliceBridge. Вернитесь в AliceBridge
   и следите за статусом.
5. Приложение найдёт колонку и будет повторять подключение к ADB. После прошивки
   и перезагрузки IP может измениться — приложение отслеживает смену адреса.
   Успех подтверждается ответом ADB с `uid=0`.
6. Дождитесь этапов **отключение OTA → блокировка доменов аналитики → постоянный ADB**.
   Для **Станции 1** используется отдельный путь с root boot, описанный ниже.
   **YSE/Entware, SSH Dropbear и Zsh устанавливаются только по кнопкам с подтверждением**.
7. На экране **домашнего Wi-Fi** укажите обычную сеть и пароль. Подключите телефон
   к той же сети и дождитесь повторного подключения колонки. После подтверждения ADB
   хотспот отключится.
8. **После использования DFRoot обязательно перезагрузите телефон**: временный root
   и изменения ядра сохраняются до перезагрузки.

## Дополнительный вариант: Shizuku

Root телефона и KernelSU для этого режима не нужны. Shizuku заменяет способ запуска
хотспота и настройки DNS на телефоне. Получение root самой колонки по-прежнему зависит
от её модели и прошивки.

1. Установите [официальный Shizuku](https://github.com/RikkaApps/Shizuku/releases/latest).
2. Подключите телефон к Wi-Fi, включите режим разработчика и **Беспроводную отладку**.
3. В Shizuku откройте **Запуск через беспроводную отладку → Сопряжение**.
   В настройках беспроводной отладки выберите **Подключить устройство с помощью кода
   сопряжения** и введите код в уведомлении Shizuku.
4. Вернитесь в Shizuku и нажмите **Запустить**. Убедитесь, что служба работает.
5. В AliceBridge выберите **Shizuku · без root → Настроить Shizuku**,
   разрешите доступ AliceBridge в запросе Shizuku.
6. Отключите другой VPN и уже работающий хотспот. Нажмите **Начать через Shizuku**.
7. Дождитесь готовности точки доступа, подключите к ней колонку через «Дом с Алисой»
   и вернитесь в AliceBridge. Остальные этапы выполняются как в основном способе.
8. Для домашнего Wi-Fi введите пароль вручную: в режиме Shizuku приложение
   не извлекает сохранённый пароль сети.

После перезагрузки телефона Shizuku нужно запускать заново. Если ранее использовался
DFRoot, требование перезагрузить телефон после него остаётся в силе.

## Станция 1

Для **первой Станции** (`yandexstation`, плата `tulip`) реализовано получение
постоянного root через подготовленный **boot-root.img**. До первого подключения ADB
порядок настройки такой же, как у остальных колонок.

После подключения приложение проверяет модель и исходный boot, сохраняет резервную
копию boot на телефон, записывает подготовленный образ, сверяет SHA-256 записанного
раздела и перезагружает Станцию. Затем повторно подключается и проверяет root ADB.
Для этой модели используются отдельные этапы вместо общего сценария OTA/аналитики.
Образ не применяется к Мини, Лайт, Макс и розничной Станции 2.

- [Root boot Станции 1](http://78.24.223.83/station1/boot-root.img).
- [Заводской boot Станции 1](http://78.24.223.83/station1/boot.img).
- Сброс настроек колонки **не восстанавливает заводской boot**.

## Панель управления

Если ADB уже доступен, приложение открывает панель управления. Если найдено несколько
колонок, предлагает выбор. Доступны сведения о модели и прошивке, пакеты YSE
(Entware и `.yap`), интерактивный терминал, SSH, Zsh и смена домашнего Wi-Fi.
Установки YSE/Entware, SSH и Zsh требуют отдельного подтверждения.

SSH: пользователь **root**, начальный пароль **1**, порт **2222**;
для Станции 1 — **22**. Zsh настраивается с темой `adam1`, историей,
автодополнением и окружением для терминала приложения и SSH.

В журнале подробности ADB и DNS сворачиваются. **Поделиться диагностикой** открывает
системный диалог отправки ZIP с подробным журналом и состоянием сети. При запуске
AliceBridge проверяет обновление и показывает список изменений с кнопками
**«Обновить»** и **«Пропустить обновление»**.

## Как это работает

- **На телефоне:** встроенный [DFRoot](https://github.com/diabl0w/DFRoot) использует
  уязвимость ядра для временного root через KernelSU. Нужны совместимое ядро и ARM64;
  одна версия Android совместимость не гарантирует. Уже имеющийся root можно использовать
  без DFRoot. Дополнительный Shizuku управляет тестовой сетью и хотспотом без root телефона.
- **На колонке:** DNS направляет запросы настройки на сервер `78.24.223.83`, который
  возвращает конфигурацию с включённым root ADB. При необходимости предлагается откат
  на выбранную прошивку. Для Станции 1 постоянный root закрепляется отдельным boot.

## Если не работает

- **Ошибка Bluetooth в «Доме с Алисой»:** полностью закройте «Дом с Алисой»,
  откройте заново и повторите подключение.
- **Root не получен:** проверьте менеджер и совместимость ядра с DFRoot.
  Можно вручную открыть инструкцию экспериментального режима Shizuku.
- **Нет прав `su`:** выдайте AliceBridge доступ в разделе «Суперпользователи» KernelSU.
- **Нет интернета у колонки:** проверьте в настройках AliceBridge IP DNS —
  `78.24.223.83`, отключите другой VPN и посмотрите ответы DNS в журнале.
- **ADB ещё недоступен:** дождитесь перезагрузки колонки и проверьте журнал.
  Повторные подключения выполняются автоматически; открытие порта ADB не гарантируется.
- **Нужен разбор проблемы:** отправьте ZIP через **Поделиться диагностикой**.

Сервер основан на [lite-kit](https://github.com/krevetkqqq/lite-kit),
пакеты устанавливаются через [YSE](packages.md).

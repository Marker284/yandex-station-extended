    ТВ-набор для Станции 1¶

    Один скрипт устанавливает веб-пульт, Couchy Launcher, SmartTube и v2rayNG. Пульт открывается в браузере телефона; управление передаётся Станции по локальной сети.

    Проверено на: Станция 1 (tulip), Android 6.0.1 / SDK 23, сборка MOB30J.20261013, root и SSH от AliceBridge, HDMI, 28 октября 2026. На других моделях не проверялось.

    Что понадобится¶

    • Станция 1 с root и включённым SSH от AliceBridge.
    • Телевизор или монитор по HDMI для работы с приложениями.
    • Телефон с AliceBridge и браузером в той же Wi-Fi-сети.
    • Интернет на Станции для загрузки отсутствующих APK.

    Что ставится¶

    Компонент Назначение
    Веб-пульт Управление Android, запуск приложений, текст, настройки и Wi-Fi
    Couchy Launcher 1.0.6 ТВ-лаунчер
    SmartTube stable 32.68 YouTube-клиент для ТВ
    v2rayNG 1.9.45 VPN-клиент для Android 6

    Сервер пульта и страница уже встроены в установщик. Отсутствующие APK скачиваются из закреплённых официальных GitHub-релизов; перед установкой проверяется SHA-256. Установленные приложения пропускаются вместе с их настройками и данными. Entware, lighttpd, Java, Python и Android SDK для установки не нужны.

    Установка¶

    1. Если SSH ещё не установлен, включите его в панели AliceBridge. Это создаёт штатный автозапуск /data/dropbear/start.sh, который использует пульт. Повторно получать root или сбрасывать уже настроенную колонку не нужно.

    2. В AliceBridge откройте интерактивный терминал колонки и выполните:

      base=https://raw.githubusercontent.com/Marker284/yandex-station-extended/main
/system/bin/curl -fL --cacert /system/vendor/quasar/ca-certificates.crt \
  "$base/contrib/station1-tv/install.sh" -o /data/local/tmp/station1-tv.sh &&
sh /data/local/tmp/station1-tv.sh

      Скрипт проверяет модель и root, ставит отсутствующие приложения, сохраняет резервную копию, запускает пульт и проверяет ответ сервера. /system и boot не изменяются; перезагрузка и остановка Алисы не выполняются.

    3. Откройте напечатанную ссылку первого запуска на телефоне в той же сети Wi-Fi. Пароль задаёт сам пользователь, минимум 8 символов. Одноразовый код первого запуска уже находится в ссылке; до установки пароля команды управления недоступны. После этого используются обычный адрес http://<STATION_IP>:8080/ и заданный пароль.

    Повторный запуск той же команды обновляет пульт, сохраняя пароль и настройки. Для установки только пульта, без загрузки приложений:

    sh /data/local/tmp/station1-tv.sh --remote-only

    Если установщик уже передан на колонку, выполните sh <путь-к-файлу>: другие файлы рядом не требуются. Интернет нужен только для загрузки отсутствующих APK.

    Альтернатива: установка с Windows

    Из клона репозитория:

    powershell -ExecutionPolicy Bypass -File contrib/station1-tv/install.ps1 -Ip <STATION_IP>

    Нужен штатный OpenSSH. Необязательные параметры: -Key <SSH_KEY>, -Port <SSH_PORT>, -BindAddress <LOCAL_IP> и -RemoteOnly. Этот установщик также содержит сервер и интерфейс внутри одного файла.

    HTTP не шифрует пароль и команды

    Пароль защищает управление Станцией от других участников сети. Сервер привязан к IPv4-адресу wlan0, а команды требуют сессию и проверку Origin/CSRF. Транспорт — HTTP: пароль и команды не шифруются в сети. Порт 8080 нельзя пробрасывать в интернет; пользоваться следует в доверенной Wi-Fi-сети. Пароль root для SSH настраивается отдельно.

    Пульт¶

    • Стрелки, OK, назад, меню, воспроизведение/пауза, громкость и отключение звука.
    • Удержание стрелок и громкости с повтором; отпускание при потере соединения.
    • Запуск Алисы, Couchy, SmartTube, v2rayNG, настроек Android и Wi-Fi.
    • Ввод текста, цифр и символов. Кириллица вставляется через буфер обмена и Ctrl+V, если активное приложение поддерживает вставку. На проверенной прошивке временный текст очищается из буфера после вставки; прежний буфер прочитать root не разрешено.
    • Смена пароля и выход из пульта.
    • Управление стрелками, Enter и Escape с клавиатуры компьютера.

    При 30 командах по Wi-Fi медиана ответа WebSocket составила 4 мс, p95 — 9 мс; обработка кнопки внутри сервера — около 1–2 мс. Прежний CGI с input keyevent занимал около 1,2 с. Это измерение команды, а не отрисовки кадра на телевизоре; задержка зависит от сети и приложения.

    В «Параметрах» доступны импорт VPN-ссылки, выбор лаунчера при следующем включении и перезагрузка с подтверждением.

    При загрузке Couchy голос Алисы может отключиться

    Этот режим выгружает приложение Яндекса, поэтому Алиса может перестать отвечать голосом. По умолчанию остаётся Алиса. Автоматический запуск Couchy проверен на Станции 1 после настоящей перезагрузки 28 октября 2026 года.

    VPN и YouTube¶

    1. Откройте «Параметры» → VPN, вставьте vless://, vmess://, trojan://, ss:// или HTTPS-ссылку подписки и нажать добавление.
    2. На телевизоре проверьте результат импорта в v2rayNG.
    3. Выберите профиль, включите его и при первом подключении подтвердите запрос Android на VPN.

    Для v2rayNG 1.9.45 ссылка кодируется дважды: приложение последовательно вызывает getQueryParameter и URLDecoder. В ссылках REALITY исправляется лишнее экранирование spx: начальный / сохраняется без процентного экранирования, чтобы ядро REALITY не получало недопустимый путь %2F на Android 6. Импорт настоящего ключа в v2rayNG, работа VPN и воспроизведение YouTube через VPN подтверждены владельцем Станции 1 28 октября 2026 года.

    Откат и отключение¶

    Перед обновлением файлы сохраняются в /data/station-remote/backups/. Путь последней копии находится в /data/station-remote/last-backup.

    Возврат к предыдущей версии этого Java-пульта с сохранением текущего пароля:

    (
  set -e
  dir=/data/station-remote
  backup=$(cat "$dir/last-backup")
  case "$backup" in "$dir"/backups/*) ;; *) exit 1;; esac
  for f in station-remote.jar index.html remote-start.sh; do
    [ -f "$backup/$f" ] || { echo 'Нет полной копии Java-пульта'; exit 1; }
  done
  sh "$dir/remote-start.sh" stop
  for f in station-remote.jar index.html remote-start.sh; do
    cp -p "$backup/$f" "$dir/$f"
  done
  sh "$dir/remote-start.sh" now
)

    При первом переходе со старого CGI в копии сохраняются также его файлы автозапуска legacy-*. Команда выше относится к последующим обновлениям Java-пульта.

    Остановить пульт и отключить автозапуск, сохранив данные и приложения:

    sh /data/station-remote/remote-start.sh stop
/sbin/busybox sed -i '\|/data/dropbear/remote.sh|d' /data/dropbear/start.sh

    Повторный запуск установщика снова включает автозапуск.

    Как это работает¶

    • Один Java-процесс запускается штатным Android app_process. Он обслуживает HTTP и WebSocket, передаёт кнопки через InputManager и запускает экраны через ActivityManager. Для обычных кнопок не создаются процессы input, am или monkey.
    • Скрипт в /data/station-remote/ наблюдает за процессом и адресом Wi-Fi. При смене адреса он перезапускает только пульт с новой привязкой.
    • Пароль хранится как PBKDF2-хеш с солью в auth.properties, а не открытым текстом. Сессия передаётся в HttpOnly/SameSite-cookie; она действует 12 часов.
    • Исходники и сборка находятся в contrib/station1-tv/. Для пересборки нужны Python, JDK и официальный D8/R8.

    Ограничения¶

    • Проверка относится к Станции 1 / Android 6, а не ко всем моделям Яндекса.
    • Bluetooth-пульт не требуется: управление идёт через Wi-Fi.
    • Вставка текста зависит от поддержки Ctrl+V активным приложением.
    • Если пульт перестал открываться после смены сети, нужно узнать новый IP Станции.
    • Установка при отсутствии всех трёх APK проверена на Станции 1. Проверка не включала заводской сброс или получение root с нуля.
